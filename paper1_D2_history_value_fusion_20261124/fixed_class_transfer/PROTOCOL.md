# D2静态健康预算与固定链路类别权重的迁移审计

日期为2026年11月26日。冻结D2输入为d6d958348ec3bbc73fe42df0a9e9cf8a337a8d78，D1输入为7e32a41b9802438f6645d9048ee46386caa53418。实验在独立分支d2-fixed-class-transfer-20261126执行，物理系统为原四维局部不可观测common-G。

## 研究对象

父版本B2中HC-static与HC-dynamic动作相同。初始回读还显示，HC-static在每个场景的报警权重只取一个固定值。该观察来自旧开发数据，本轮先进行有限状态等价性审计，再用新物理路径检验冻结策略迁移。

保持12个场景、连续与突发两种输入、原H1、原M7数值筛查、原候选权重0、0.2、0.4、0.6、0.8、0.9、1。风险表、H1阈值和健康预算均直接冻结自B2，各场景沿用其固定表。新路径评价时只执行策略。统计解释为冻结策略的独立路径迁移审计，研究阶段沿用开发筛查定位。

## 四个策略

R1沿用冻结风险表，在其自身M7可行集上最小化U1。

HC-static沿用冻结静态健康预算，在M7与静态健康可行集交集上最小化同一U1。

Class-model按拓扑、目标链路角色和动力学冻结一个报警权重。U35在不稳定模型取0.8，在稳定模型取0.6，R35与R1均取0。它们取自父版本静态可行集的最小候选，无额外参数拟合。该基线允许与HC-static相同的物理模型知识。

Class-topology在两种动力学间共享权重。U35取0.8，R35与R1均取0，由Class-model在两种动力学上的较大权重确定。它考察粗链路类别的保守迁移。

所有策略在目标链路未报警时取q=1，其他报警边使用相同冻结二元门控。两个固定类别策略分别维护自己的M7历史，若请求权重不合法，则取大于等于请求值的最小合法候选，q=1保底。风险最小化的并列仍采用原1e−10目标容差内较大q。

## 等价性与新路径

对每场景Class-model请求值与q=1构成的全部64个六拍历史，枚举M7合法性。对冻结风险表的全部13个单元和这些历史，检查HC-static的动作是否等于Class-model。若全部成立，可用六拍状态归纳证明任意目标H1报警序列上的动作等价，进而得到相同输入下的估计轨迹相同。

另从新namespace[20261126,88403,1]生成每个场景—输入条件512条攻击路径、每场景1024条健康路径。物理与攻击生成器完整复用父版本接口，stage2用于攻击物理与扰动，stage1用于健康。冻结风险表的旧拟合路径、新评价路径和健康评价路径分开登记。健康阈值沿用父版本，实际新健康FWER给计数及精确二项区间。

## 端点与统计

主要结果为HC-static与Class-model的逐拍动作差异次数及接收节点缺失块受扰期MSE配对差。完整报告恢复期、健康20至149拍、全网误差和目标/全边FWER。Class-topology、R1为次要比较，分不稳定U、稳定U、两种R链路角色和两种输入分别报告。对连续与突发场景分层按完整物理路径进行10000次配对bootstrap。
