# D2-B 预执行审计

## 审计结论

D2-B 的四策略结构可以执行，但需要在运行前补齐以下定义。当前不授权启动攻击或健康路径。

## 已通过项目

| 项目 | 审计结论 |
|---|---|
| 四个策略 R1、RH-static、RH-scalar、RH-dynamic | 保留 |
| 新随机命名空间 | 与 B1、B2、A 的命名空间不同，运行时仍须做种子集合审计 |
| 健康校准、攻击拟合、攻击评价分离 | 设计要求合理 |
| 四维 common-G 主模型 | 与 D2 研究对象一致 |
| 二维 common-G | 只作为历史回归，不并入四维主结果 |
| M7 可行图 | 可作为数值筛查，不能称严格稳定性证明 |
| 四策略共享 H1 掩码 | 适合识别融合决策增量，必须验证 H1 无估计器反馈 |

## 必须在运行前冻结的修正

### 1. 风险表身份

条件风险上界 $U_1(qmid s',r)$ 使用 A′ 同先验单拍标签和攻击拟合路径建立。四个策略共享这张表。它是**冻结参考先验下的动作排序代理**，不是各策略自身闭环 MSE 的上界。

每个策略必须另外保存自身动作历史、实际动态 $H_k$、支持单元和风险表回退次数。B 报告需同时给出风险代理与实际闭环 MSE 的排序。

### 2. 健康代价的模式索引

完整接纳延续必须使用目标弧无报警模式的 $F_1$ 和 $Omega_1$。当前报警候选使用报警模式下的 $F(q)$ 和 $Omega(q)$。不能把报警位为 1 的 $q=1$ 模式当成未来完整接纳模式。

$H_*$ 和 $H_k$ 的初始后验都必须明确取无报警完整接纳的 $P_+$。运行前用一拍矩阵递推和 D1-A 固定点结果回归。

### 3. RH-scalar 的拟合域

$a_k$ 定义为当前策略自身动态健康代价和固定初始代价之间的非负最小二乘系数

$$
a_k=argmin_{age0}sum_{qinmathcal Q_k^{m stab}}
left[H_k(q)-aH_*(q)ight]^2.
$$

拟合只在当前稳定性可行集上进行。分母为零时固定 $a_k=0$，并记录零分母次数。不能用全网、闭环 MSE 或评价路径真值反向选择 $a_k$。

### 4. 风险表拟合和路径划分

连续与突发路径可在相同水印条件下合并拟合，但必须保存来源标签、每个来源支持路径数和各自敏感性结果。每个单元的最低支持是不同路径数，不是报警拍数。

B 的 256 条拟合路径和 256 条评价路径只构成开发筛查。不得报告确认性显著性。每个条件输出路径级配对差、描述性区间、回退比例和分歧拍数量。

### 5. 阈值和 H1 反馈

每个场景使用新的 256 条健康校准路径确定阈值，另用 256 条健康评价路径计算给定阈值的 FWER。四个策略必须逐位共享同一 H1 报警掩码。

需要执行一个确定性断言。用同一健康路径分别运行四个策略，H1 分数和掩码必须逐位相同。若检测分数读取估计器状态，B 必须停止并报告接口不符合当前冻结 H1 定义。

### 6. 新路径和旧路径隔离

运行前记录以下哈希和种子信息。

- D2-B 协议提交
- main、D1、A′ 提交
- 物理配置
- H1 源文件
- D1 模式表和 M7 图
- B2/A 输出哈希
- 新健康与攻击种子清单

新种子不得与 B1、B2、D2-A 或 D2-A′ 的种子元组重复。程序必须拒绝读取旧 B2/A 路径作为 B 的物理输入。

### 7. 统计输出

B 的主比较固定为 RH-dynamic 减 R1。次比较固定为 RH-dynamic 减 RH-static 和 RH-dynamic 减 RH-scalar。每个比较报告：

- 攻击窗口缺失块 MSE
- 恢复窗口缺失块 MSE
- 健康 MSE
- 路径级配对差和描述性区间
- 动作分歧率
- 风险表回退率
- 有效权重
- 污染拍未报警率
- 策略自身动作历史长度

12 个物理场景等权汇总，水印和攻击时序的汇总规则在运行前固定。B 不启动 C。

## 运行前验收门槛

1. 四个策略的 H1 掩码逐位相同。
2. 四个策略无报警拍均取 $q=1$。
3. 每个动作都属于 M7 可延续集合。
4. $H_*$ 的无报警模式固定点回归通过。
5. RH-scalar 零分母与回退处理有计数。
6. 每个风险单元支持数、路径数和来源标签完整保存。
7. 新路径种子与所有历史命名空间无交集。
8. 所有输入哈希在运行前写入机器可读清单。

满足以上条件后才可以生成 B 的新路径。
