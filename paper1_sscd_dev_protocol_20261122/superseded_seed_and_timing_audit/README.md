# Superseded SSCD v2 run (preserved for audit)

This was the first physical development/test run using development seed `2026112701` and final-test seed base `2026112242`. It is retained byte-for-byte because later audit found:

- transition-direction RNG seeds collided across different angle/policy combinations;
- the final-test MSE/TPR helper used fixed attack windows `[50,110)` and eligible-score windows `[57,110)`, even for onset65 scenarios.

The source snapshots are included. Do not use these output arrays as the corrected v2 final test. The development split also used the pre-final ratio selector with 60 one-sided bounds; the corrected selector now uses a numerator upper bound and sign-dependent denominator endpoint with 72 bounds.

The current top-level `development_*` and `final_test_*` artifacts are generated by the corrected seed namespaces, corrected ratio bounds, and onset-specific windows. This preserved run is not deleted or overwritten in place.
