## 1. 审阅结论与新阻断缺陷

原 `paper1_gate_aware_theory_20261122/dev_selection.py` 用严格 `if info_nats[name] > info_budget` 排除超限项，而二维 Watson 核在原登记参数 `theta=±1.315236976827179` 下，用 70 位 mpmath 计算有

```
I_2(theta) = 0.100000000000012844080470686606739...
```

这不仅是 SciPy 浮点算术偏差：**原参数字面值高精度下也略超过0.1预算约 1.2844e-14**。原程序会因此把这项候选完全排除。新的 `project_theta` 仅对超限量不超过 `1e-11` nats 的注册边界候选进行**向可行域内部重投影**；保持高精度二次核互信息严格小于预算，同时记录调整。

例如 `theta=-1.315236976827179` 自动修正为 `theta=-1.3152369768257723`，其 MI 为 `0.09999999999981500...`。这是一项数值安全修复，不能改变原论文的理论参数，也不能悄悄复写历史128/64路径计算参数。此前结果继续原样归档。

## 2. 实际已审阅结果（不是本包新仿真）

对提交 `b9fc33c` 的64路径路径级风险界审计，负耦合相对 iid：

| 物理配置 | `U_attack` 降幅 | `U_total` 降幅 | 配对污染 `J_b` 降幅 | 全时段受攻 `J_a` 降幅 |
|---|---:|---:|---:|---:|
| 不稳定模型 | 2.29% | 1.91% | 2.05% | 0.071% |
| 稳定模型 | 16.27% | 15.53% | 15.76% | 0.917% |

风险界与实际受攻击**绝对 MSE**比约1.33–1.54；但如果以配对偏差能量 `J_b` 为分母，保守界松弛约1.17–1.18。**两种风险口径不能混写。** 这个约束证书不能推出两个水印的真实最终 MSE 排序；该轮64路径也没有按场景重新选参。

原四世界128路径结果：不稳定模型总全网 MSE 差 `−0.000158`、稳定模型 `−0.000588`；固定门控的水印直接项两模型95%区间均跨零；稳定模型的门控调度项显著小于零，不稳定模型仍跨零。Shapley分解是受控门控序列的路径级代数归因，不是未知自适应攻击者下的普遍因果定理。

## 3. 本包实现了什么

- `selector_v2.py`：高精度有符号 Watson 互信息、边界参数向内校正、paired loss difference 的同时一侧上界、iid baseline 的同时正下界和输入 SHA-256。只接受标记为 `development` 的独立开发路径 JSON，拒绝 `test`。Student-t 界对偏态路径损失仍是近似。
- `run_development.py`：需要**完整的纸一 GitHub 工程目录**才可执行。启动前验证四个原始源文件 SHA-256，不更换原共 G、`plugin-KL` 或六链路架构。用独立健康校准设定原检测阈值；两种动力学、三种原六链路共同虚拟状态方向、两种攻击起点，共12个开发场景，在每个场景中配对比较五个有符号水印候选，输出开发损失和锁定决策。
- `test_protocol.py`：测试互信息边界修正、原始攻击能量保持及攻击时间搬移、错误数据划分拒绝、冲突场景退回 iid。

**注意**：`run_development.py` 的非零旋转与第二起点是**新登记的压力场景**，不是原稿历史攻击的原封不动复现，不是未知攻击支持集试验。它固定原6条接收边和原攻击持续60拍；为公平比较方向，仅将旋转后的**联合编码域能量**标准化为当前模型的原始联合能量。

## 4. 目前采用的候选和信息预算

在本论文原来的 `m=2` 量测下，每条时间链的相邻互信息预算取 **0.1 nats/step**。只将下面五项送进物理开发集：

| 候选 | 实际 θ | 相邻互信息 (nats) |
|---|---:|---:|
| 负耦合-边界 | −1.3152369768257723 | ~0.099999999999815 |
| 负耦合-弱 | −0.6 | 0.02212654 |
| iid | 0 | 0 |
| 正耦合-弱 | +0.6 | 0.02212654 |
| 正耦合-边界 | +1.3152369768257723 | ~0.099999999999815 |

`theta=±2` 的相邻互信息各约0.210476 nats，**超过此预算**，不需要浪费开发集算力。注意0.1是**每条时间链/每相邻时刻**的统计依赖预算，不是全部50传感器的总联合信息泄露量，也不是密码学保密保证；5拍窗口内同一链的总相关约0.4 nats。

## 6. 真正未知攻击支持集：单列工程任务

当前6边专用原检测器**不能**直接证明未知攻击支持集安全性。原50节点网络有298条无向边，即596条有向报文链接；若扩展到全部有向边，需同时完成：

1. 按发送端重建所有596条链路的奇偶空间和名义残差协方差，重新校准整个网络全时段的最大 `plugin-KL` 分数（整路径 FWER），不能沿用6边阈值。
2. 原 `64` 个全网掩码不再覆盖全部候选边；应采用按接收节点活动邻居集合的**惰性缓存增益计算**（首次遇到集合时 DARE 设计、检查增益、缓存），不能试图预分配 `2^596` 个掩码；需要重新检查这些新增活动集合是否满足统一收缩界。
3. 不允许给静态基线知道未来真实攻击边，同时不给 SSCD 这类信息。可同时提供候选边已知的静态删边 oracle 和在相同平均删边预算下、未知支持的非 oracle 静态基线，但要明确二者信息权限不同。
4. 此未知支持集架构**本包没有实现、没有仿真**；不得把原6边旋转方向实验称作未知支持集验证。

## 7. 审稿人视角目前可写的结论

水印时序耦合的实验效应可以叙述为：新共 G 下负耦合在既定六边攻击和固定门控机制下可降低最终受攻 MSE，其效果主要体现在改变门控时序，直接水印项尚未被统计区间稳定区分。路径级收缩界给出了数据相关门控的风险控制证明，但没有提供对 iid 的排序定理。

是否存在**真正的系统感知选参算法的外推价值**，需要依赖此次新的开发集能否锁定候选及后续独立测试表现。若12个开发场景的某一个出现不可忽略的损害，该保守选择器将如实退回 iid；这是一种合理的失败结果，不应事后删场景。
