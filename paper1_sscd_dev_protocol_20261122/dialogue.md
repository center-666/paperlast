# SSCD v2：会话与执行记录

本目录记录用户提交的 v2 研究建议、独立复核、开发集执行和锁定后终验。不可见的原始 API 工具内容没有补造。

用户指出原 selector 的严格浮点预算判断会错排 θ=±1.315236976827179，并提出向可行域内投影、12场景独立开发、锁定后另用新校准/测试，以及同时区分 (U_{attack})、(U_{total})、(J_b) 和绝对 (J_a)。

本轮动作：

1. 从 Downloads 发现并解压 `paper1_sscd_dev_protocol_20261122.zip`，保存原压缩包字节与哈希。
2. 独立复核互信息高精度投影和开发场景生成；发现相对风险 UCB 还需计入 iid 分母不确定性，改为同时 paired-difference 上界与正基线下界，并作 Bonferroni 校正。
3. 完成512条校准、12场景×256开发路径。所有场景均使用新随机流且路径ID全局唯一。按锁定规则选择 iid。
4. 以全新随机流完成512条独立健康测试、12场景×512终验路径。完整候选结果保存，但终验没有回灌改写 iid 锁定。
5. 验证开发损失、锁定文件、源代码哈希、路径划分和路径级最终数组。

研究结论：开发集没有证明任何耦合候选在全部场景均优于 iid，因此系统感知选择器正确回退 iid。锁定后测试显示负边界候选在两模型的各6个场景均为较低 MSE，但只能作为该候选的终验描述，不能据此追溯重选。
