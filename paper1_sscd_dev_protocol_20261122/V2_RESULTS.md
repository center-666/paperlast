# SSCD v2 开发集选参与独立终验

此记录严格区分开发选择与最终测试。参数锁定文件在终验前生成；终验中即使其它固定候选结果更好，也没有据此改写锁定参数。

## 互信息边界修复

70位计算得到原登记 θ=±1.315236976827179 的相邻互信息为 `0.100000000000012844...` nats，略超0.1预算。v2 将候选向可行域内投影到 θ=±1.3152369768257723，MI=`0.099999999999815004...`。历史实验参数和历史结果不变。

选参器还修复了相对风险 UCB 的分母问题：对每个配对损失差构造单侧上界，并对 iid 平均 MSE 构造严格为正的单侧下界；随后用“差值上界/基线下界”。Bonferroni 同时覆盖48个候选/场景分子界和12个场景分母界，共60项。区间基于 Student-t，对偏态的路径 MSE 仍属近似。

执行后的完整路径ID核验又加了一项只读守卫：当前 selector 要求所有开发场景间的路径 ID 全局唯一。该守卫是在开发集运行后追加的，不改变选择计算。验证程序从当前源移除这段新增守卫后，SHA-256 与开发清单记录的 selector 哈希一致；用当前 selector 重算，也得到逐字段相同的锁定文件。

## 开发集结果与锁定

开发集包括2个动力学、3个攻击方向（0°、±45°）和2个攻击起点（50、65），共12个事前登记场景。每场景256条新物理路径，每模型512条独立健康校准路径，共3072个全局唯一开发路径ID。路径来自新场景随机流，没有读取或复用早前测试文件。

开发路径 RNG seed 为整数 `2026112701`；该值是随机数标签，不代表运行日期。本轮执行日期为2026-11-22。

候选为边界负、弱负、iid、弱正、边界正。v2 的保守规则要求最坏场景同时相对风险上界严格小于零。结果锁定为 **iid，θ*=0**。

边界负耦合在12个场景点估计均比 iid 低，但不稳定模型的 `−45°/onset50` 与 `−45°/onset65` 同时上界分别为 `+0.01999%` 和 `+0.01186%`；因此没有通过“全部登记场景都认证不劣/更优”的规则。其它非 iid 候选的最坏同时上界也为正。这是开发集未能认证耦合收益，按协议回退 iid。

各候选最坏同时相对上界为：

| 候选 | 最坏同时相对上界 |
|---|---:|
| iid | 0% |
| 边界负 | +0.01999% |
| 弱负 | +0.19682% |
| 弱正 | +0.84712% |
| 边界正 | +1.79043% |

### 健康误报与 oracle

独立健康终验512条路径上，整路径任意报警：不稳定模型 `29/512=5.664%`，精确二项95% CI `[3.826%,8.034%]`；稳定模型 `19/512=3.711%`，区间 `[2.249%,5.735%]`。每步/整路径阈值仍使用 rank488 的路径最大值校准。25/513≈4.8733% 是校准和未来路径的联合边际界，不是条件于固定已校准阈值的保证；不稳定样本值高于5%应如实保留。

终验中静态删除已知六边的全网 post20 MSE 为不稳定 `0.0604138`、稳定 `0.0603901`。边界负耦合仍分别高约1.595%和6.459%，静态已知候选 oracle 仍占优。未知攻击位置尚未验证。

## 解释

本次 v2 选参器按“所有登记场景都要满足同时风险上界”的强规则回退 iid；而锁定后的独立终验中，边界负耦合实际在所有已登记压力场景都呈现较低 MSE。两者并不矛盾：这是开发样本下置信上界略未通过，但新测试对固定候选提供了进一步方向证据。因为终验只能验证已锁定 iid，本次不把测试结果回灌以更改 θ*。

下一轮若继续寻求非 iid 锁定，需要先登记更大或更有效率的独立开发设计，再另用全新校准和测试路径验证；本轮测试数据不能再用于选参。还需与静态删除 oracle 比较，并保持未知支持集结论单列。
