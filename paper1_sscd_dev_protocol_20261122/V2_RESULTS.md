# SSCD v2 开发集选参与独立终验

此记录严格区分开发选择与最终测试。参数锁定文件在终验前生成；终验中即使其它固定候选结果更好，也没有据此改写锁定参数。

审计发现初次运行存在跨场景转移方向种子碰撞及起点65统计窗口未平移的问题，且首版相对界还未覆盖负分子时的分母上端点。旧运行完整保存在 `superseded_first_run_seed_collisions/` 和 `superseded_seed_and_timing_audit/`，不作为下列最终结果。最终开发/终验采用72项同时界、不重叠的种子命名空间及按 onset 移动的窗口。

## 互信息边界修复

70位计算得到原登记 θ=±1.315236976827179 的相邻互信息为 `0.100000000000012844...` nats，略超0.1预算。v2 将候选向可行域内投影到 θ=±1.3152369768257723，MI=`0.099999999999815004...`。历史实验参数和历史结果不变。

令 (D) 为配对 MSE 差、(B>0) 为 iid 平均 MSE。选参器同时构造单侧分子上界 (U_D) 和基线区间 ([L_B,U_B])，并计算

$$\operatorname{UCB}(D/B)=\begin{cases}U_D/L_B,&U_D\ge0,\\U_D/U_B,&U_D<0.\end{cases}$$

当分子上界为负时必须除以更大的基线上界；除以下界会错误地得到过于负的“上界”。Bonferroni 覆盖48个候选/场景分子界和24个基线端点界，共72项。Student-t 对偏态路径 MSE 的覆盖仍属近似。

首轮执行后增加了跨场景路径 ID 全局唯一守卫。当前修正版在该守卫已存在的情况下重新生成独立开发集，记录的 selector 哈希与当前源码直接一致；验证程序还重新计算完整锁定文件并逐字段核对。

## 开发集结果与锁定

开发集包括2个动力学、3个攻击方向（0°、±45°）和2个攻击起点（50、65），共12个事前登记场景。每场景256条新物理路径，每模型512条独立健康校准路径，共3072个全局唯一开发路径ID。路径来自新场景随机流，没有读取或复用早前测试文件。

开发路径 RNG seed 为整数 `2026112702`；该值是随机数标签，不代表运行日期。本轮执行日期为2026-11-22。物理、径向、初始方向和转移方向种子分属不重叠命名空间；径向与初始方向只在同一场景的候选间共享。

候选为边界负、弱负、iid、弱正、边界正。v2 的保守规则要求最坏场景同时相对风险上界严格小于零。结果锁定为 **iid，θ*=0**。

边界负耦合在12个场景点估计均比 iid 低，但不稳定模型的 `−45°/onset50` 与 `−45°/onset65` 同时上界分别为 `+0.03120%` 和 `+0.00696%`；因此没有通过“全部登记场景都认证不劣/更优”的规则。其它非 iid 候选的最坏同时上界也为正。这是开发集未能认证耦合收益，按协议回退 iid。

各候选最坏同时相对上界为：

| 候选 | 最坏同时相对上界 |
|---|---:|
| iid | 0% |
| 边界负 | +0.03120% |
| 弱负 | +0.16952% |
| 弱正 | +1.10859% |
| 边界正 | +1.81298% |

## 独立终验

边界负耦合相对 iid 的 network post20 差在不稳定、稳定模型各自6/6场景均为负；负边界 eligible TPR 分别提高0.190和3.606个百分点，平均首警延迟分别缩短0.055和0.080拍。这个终验结果支持候选在新路径上的方向性收益，但**不能追溯替换 iid 锁定**，也不能把描述性区间当作开发选择的认证。

### 健康误报与 oracle

512条校准路径给出的阈值为不稳定 `60.024062`、稳定 `59.801490`。在独立健康终验512条路径上，整路径任意报警：不稳定模型 `28/512=5.469%`，精确二项95% CI `[3.664%,7.807%]`；稳定模型 `38/512=7.422%`，区间 `[5.305%,10.045%]`。每步/整路径阈值仍使用 rank488 的路径最大值校准。25/513≈4.8733% 是随机校准集与未来路径联合分布下的边际界，不是条件于固定已校准阈值的保证；稳定模型本次经验整路径误报高于5%，应在独立重复中检查。

锁定 iid 在这批独立健康测试路径上的network post20 MSE为不稳定 `0.059514`、稳定 `0.059630`。相应配对oracle统计也基于同一批物理路径，数值可从 `final_test_results.json` 和路径NPZ重算。

终验中静态删除已知六边的全网 post20 MSE 为不稳定 `0.0603523`、稳定 `0.0603280`。边界负耦合仍分别高约1.662%和6.237%，静态已知候选 oracle 仍占优。未知攻击位置尚未验证。

## 解释

本次 v2 选参器按“所有登记场景都要满足同时相对风险上界严格小于零”的规则回退 iid；负边界的12个开发点估计虽然均低于 iid，但两个不稳定 −45° 场景的同时上界仍为正，最坏 `+0.03120%`。锁定后独立终验中，边界负候选在每个动力学的6/6压力场景都呈现较低 MSE。终验只能验证 iid 锁定并作候选描述，不能回灌改写 θ*。

下一轮若继续寻求非 iid 锁定，需要先登记更大或更有效率的独立开发设计，再另用全新校准和测试路径验证；本轮测试数据不能再用于选参。还需与静态删除 oracle 比较，并保持未知支持集结论单列。
