# B2 指标口径修正记录

首轮 B2 归档中的 `target_attack_accept_fraction` 使用了 50–109 全窗口作为分母。突发攻击仅在 36/60 拍注入，因此该值混入了 24 拍正常通信间隙。软融合器并不二元接纳或拒绝报文，这个指标实际表示攻击拍中没有 H1 报警的比例。

修正后，`target_attack_accept_fraction` 只对实际注入攻击的拍计算，并在报告中标记为“污染拍未报警率”。新增 `target_window_accept_fraction` 保留完整 60 拍窗口中未报警比例。分析报告还单独给出突发正常间隙未报警率和攻击拍漏检率。软融合对报警报文造成的剩余污染由 MSE 和有效攻击权重反映。

主实验、独立核验和统计分析使用相同的 B2 随机种子、健康阈值、策略锁定表和物理路径。此次重跑是对确定性指标计算的修复，不是独立重复实验，也不增加样本量。首轮归档保留在 `b2_attack_results_pre_metric_correction`，以便审计。
