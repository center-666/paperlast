## 解释边界

污染拍接纳率只在真实注入攻击的时刻计算。突发攻击的正常间隙另行记录在 analysis.json 的 target_burst_gap_accept_fraction 中。配对差按同一条新攻击路径计算，区间是未校正的双侧 95% t 区间，属于描述性统计。BD 是 B/D 的去重执行，不能由本轮结果估计 D−B 的攻击增量。C 与 BD 的差异只表示在冻结 B1 策略下的描述性差异。B1 的健康路径未进入本轮攻击路径。不同水印条件使用独立物理随机路径，因此本表不提供负耦合与 iid 的配对因果比较。R 的 1→26 条件与原监测边 1→0 共用发送节点和传感器量测，但注入仅发生在注册的 1→26 通信弧上，H1 对两条有向边保留独立的检测位。
