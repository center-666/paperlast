# B1 事后状态与统计边界

## 状态

B1 按 B0 的冻结数值定义完成了健康校准、独立留出、路径级配对损失和核验。B1 输出本身是在 B0 文件仍标记为 \`draft_pending_manual_review\` 的工作状态下生成的。当前归档将 B1 定义为**按冻结方案执行的事后研究结果**，不把它改写成事前注册确认性实验。B1 没有单独的人工授权提交可供追溯。

这不改变 B1 的输入、种子、路径或结果。它只固定结果可以支撑的证据等级。后续任何确认性实验都必须有独立授权或正式注册提交。

## B1 事实结果

- B1-1 模式矩阵覆盖 42 张表，每张 128 个七位门控模式。独立 DARE 重建检查了 268,800 个模式—接收节点组合，最大有限矩阵差为 0。
- B1-2 使用 12 个场景，每场景 2,048 条校准路径和 2,048 条独立健康留出路径。完整留出掩码逐拍回读一致。
- B 与 D 的锁定权重相同。U 不稳定目标 35→26 为 1。其余场景为 0。两套策略在当前模型中逐拍策略等价，因此 B1 没有观察到 D 相对 B 的独立健康增量。
- 健康风险的 84 项路径级上界均通过当前登记筛选数值判据。
- H1 留出 FWER 点估计为 3.81%–6.05%，最高场景的 CP 区间为 [5.06%, 7.18%]。条件 FWER 达到 5% 的证据尚不充分。
- studentized max-\(t\) bootstrap 的覆盖诊断为统一预算 90.77%，价值预算 73.05%。这是给定本次经验分布和阈值的敏感性诊断，不是已知真实覆盖率。

## 解释边界

B1 支持健康切换实现与路径级可行性筛选。B1 不支持以下结论：

- D 优于 B。
- H1 对每个固定阈值有严格 5% 条件 FWER 保证。
- 当前 Bonferroni \(t\) 上界具有已验证的 95% 联合覆盖。
- 健康可行性自动转化为攻击防御收益。
