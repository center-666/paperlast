# B1 健康报警切换与链路权重

研究对象为 50 节点 common-$G$、四维状态和二维报文的机制模型。代码、种子、样本数和统计方案在处理正式校准和留出集前固定于提交 7868bab。每个场景有 2,048 条新校准路径和 2,048 条独立健康留出路径，合计 49,152 条。接口回归使用独立种子。

## 权重锁定结果

B 为统一 5% 预算组，D 为价值预算组。健康主指标为节点 26 缺失块在 $k=20,\ldots,149$ 的实际配对 MSE。每个场景监测原六边加当前目标，原六边在策略和基线中使用相同冻结门控。R 中另一条互补边完整接纳。下表列报警拍的权重，首个无报警拍恢复至 1。每行覆盖负耦合和 iid 两个独立场景。

|---|---|---|---:|---:|---:|
| 不稳定 | U，35→26 | 0.2、0.4、0.6、0.8、0.9、1 | 1 | 0.2 | 1 |
| 稳定 | U，35→26 | 全部七点 | 0 | 0 | 0 |

两种预算各自的 84 个健康风险上界均低于零。唯一的排除来自切换安全筛查。不稳定 U 的零权重使缺失块开环传播，模式范数达到 1.098729。其余权重在场景内所有接收节点和模式下通过 $P=I$ 收缩检查。与原固定六十拍筛查相比，可行权重增加；价值预算相对统一预算的额外排除数为零。

B 与 D 在各自可行集内比较同一个 D1-A 有限时域输入增益。不稳定 U 上，所有允许的正权重中，完整接纳的增益最小。其余场景中，零权重通过安全筛查，且对应目标输入通道增益为零。A 始终在报警拍取 0.8。C 按登记取最小可行权重。[锁定权重表](b1_health_results/policy_lock.json) · [各候选的上界与选择](b1_health_results/health_audit.json)

**同策略推论。** 对任意给定报文与 H1 报警序列，B 与 D 初值相同。每拍的目标权重、其他活动邻居、模式增益和报文相同。按估计递推归纳，两组逐拍输出相同。在当前模型与锁定表下，配对的 D−B 健康及受扰 MSE 差恒为零，两组的 Pareto 工作点重合。此推论来自策略等价性。A、C、硬门控与始终接纳的攻击损伤仍待实测。

## 模式传播的核验口径

模式模型使用 $C_m(q), V_m(q)$。B1-1 冻结说明的这一行有 Markdown 数学分隔符排版误差，以此处记法和矩阵归档为准。42 张表各有 128 个七位模式，共 268,800 个模式—接收节点组合。先前序列检查的实质性缺口是未切换第 6 位目标报警位；回退模式的 $F$ 始终为有限矩阵。定稿序列显式使用掩码 64、65、127 等，并把逐拍协方差与独立展开的噪声协方差和比较。独立矩阵重建的最大有限元素差为零。

## 健康风险及覆盖率

每条路径每个候选计算 $Z=J_{\rm sw}-(1+\epsilon)J_{\rm base}$。主上界为路径均值加 $t_{1-0.05/84,2047}=3.245712$ 倍标准误。比较族覆盖 12 场景与 7 个权重；所有模式进入同一个路径损失。两种预算分别报告各自的 84 项，没有跨预算族的联合 95% 声明。

每个场景只有 10 至 30 条留出路径触发过目标报警。令 $E$ 为目标曾报警，配对损失差 $D_r=J_{\rm sw}-J_{\rm base}$ 在 $E^c$ 上严格为零，因此 $\mathbb E[D_r]=\Pr(E)\mathbb E[D_r\mid E]$。总体健康均值受报警概率稀释，少数触发路径的损失会影响尾部推断。对于这个原始量测模型，目标降权只改变节点 26 的估计；逐路径全网 MSE 差等于节点 26 全状态 MSE 差的 1/50。

4,096 次整路径 studentized max-$t$ bootstrap 保留同路径候选间相关性。统一预算与价值预算的 95% 临界值分别约 3.63、5.73，实际可行集均与主分析一致。用主分析临界值 3.245712 对照经验重采样最大统计量，覆盖比例为 **90.77% 和 73.05%**。该诊断以经验分布及本次阈值为条件；真实联合覆盖率仍未知。这批留出轨迹独立于阈值校准，用于同时筛选和锁定候选；尚无另一批专用于锁定后健康确认的数据。Bonferroni 对单项上界的有效性有前提。可以报告预注册数值判据与敏感性分类通过，不能据此给出严格的 95% 健康风险保证。

## 复现与核验

参考环境为 Python 3.11.18、NumPy 2.4.6、SciPy 1.17.1，单线程 BLAS。在本目录运行以下命令。模式表与健康主程序要求输出目录尚不存在。可在新工作副本中先将相应输出移至副本外；两项核验可直接读取仓库归档。

~~~text
python b1_mode_models.py
python verify_b1_mode_models.py
python b1_health.py
python b1_health_analysis.py
python verify_b1_health.py
~~~

- [执行锁](B1_HEALTH_RUN.json)记录种子、批大小、样本量、统计方法和运行前的输入哈希。
- [健康归档](b1_health_results)的 12 个场景文件含校准与留出最大分数、全部七位报警掩码、七候选的逐路径三类 MSE 和切换安全范数。可从掩码恢复报警次数、持续时间、恢复权重及多边重合。
- [路径级预算量](b1_health_results/paired_contrasts.npz)保存两种预算的逐路径 $Z$、重采样最大统计量。沿实际掩码传播的协方差从初始误差协方差 $I_4$ 起步，单列作外生时序诊断。健康风险用真实状态与估计之间的平方误差计算。
- [核验记录](b1_health_results/verification.json)覆盖两个分割的 H1 分数、完整留出报警位、触发路径的逐邻居创新回放、置信上界与可行集。核验重用冻结物理生成和模型输入，采用独立白化二次型与逐邻居状态更新。模式矩阵另经[独立 DARE 重建](b1_mode_results/verification.json)。

全量独立白化复算与归档的路径最大 H1 分数最大绝对差为 $2.79\times10^{-9}$ 以内。全部留出报警位逐拍吻合。36 条选定路径含每个场景的首末目标报警路径，逐邻居直接更新与批量回放的三类 MSE 最大差小于 $1.95\times10^{-11}$。
