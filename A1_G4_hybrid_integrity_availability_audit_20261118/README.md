## 独立复算

在仓库根目录运行以下命令。运行环境为 Python 3.10 与 SymPy 1.14。脚本读取同一仓库的两份冻结目录，输出本目录的 JSON。可在工作区的第一篇研究规划下以相同目录结构运行。只需本地文件，无报文接口。

~~~powershell
python -m pip install -r A1_G4_hybrid_integrity_availability_audit_20261118/requirements.txt
python -B A1_G4_hybrid_integrity_availability_audit_20261118/verify_boundaries.py
~~~

复算从五节点保存矩阵重新生成两个共 \(G\) 的更新模式。脚本检查逐路径符号恒等式、二维矩阵的正定主子式、固定记录的协方差与 MSE 交叉项。概率用有理数级数包络，另与 G3 已存的 Arb 区间比较。不同 Python 小版本会改变输出的环境记录。矩阵与方差按冻结十进制精确读入，显示小数不替代原有理证据。输入哈希采用 UTF-8、LF 换行。

对照使用防御方的能量包络和固定可用记录。未执行攻击策略设计、报文篡改或中断，没有新增物理噪声样本。令 \(B=h=1\) 只用于参考诊断。完整声明见[登记配置](registration.json)。
