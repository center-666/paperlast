# 当前决定：C，停止方向A立项，不进入G2

日期：2026-11-15。仅对V1.0任务书已授权的G0/G1作决定。C是研究必要性与独立增量未建立的结论，不是未知相关FDI全领域不可能性定理。

## 1. 五个验收问题的直接回答

**一、同期跨传感器相关性对原时间奇偶有没有影响？** 对固定单源、固定同源边缘law及时间独立噪声，完整边缘残差过程不变，原χ²校准不变。固定预选攻击、外生水印、固定K/G及单源报警未反馈时，偏移与报警联合law也不变。条件于其他源、多源合并或数据选择起点不包括在这一结论中。

**二、空间、时空联合与聚合估计怎样变化？** 空间噪声含交叉R，独立阈值可能误校准；时空cross-covariance可被经典条件Gaussian去噪。原共G状态转移F不变、无偏性保持，正常协方差/MSE变。合法五源等相关ρ=.5时目标正常MSE约增加90%，但这不等于主攻击偏移或原单源检测风险随之增加。

**三、标准方法能解决多远？** 已知协方差的联合匹配已经用尽该Gaussian均值信息；仅知边缘和联合PSD时，标准协方差上界与χ²支配可保证单次统一误报，并集界可给固定有限测试族总体上界。未知协方差复合检验、样本校准与鲁棒水印已有成熟先例。它们不自动给最优功效或最坏危险先报警保证，但本轮没有确立一个它们无法达到的具体安全要求。

**四、与指定论文有没有实质不同的具体问题？** Niu已有共G量测求和；Greiff已有相关量测共享及误设独立代价；Olfat已有协方差集合下鲁棒水印检验；Ma已有CI与攻击检测/有界估计。其信息集、攻击权限和结论与本任务不全相同，不能说完全覆盖所有组合；也不能把这些区别或替换R当独立贡献。Zhang两篇全文仍缺，未完成定理排重。当前没有一项已成立、不能由上述标准处理替代的中心性质。

**五、方向A是否值得继续作为第一篇新防御论文？** **本轮不值得据此进入开发，判C。** 不进入G2，不再构造相关噪声集合、鲁棒检测器、水印、门控或恢复算法；不自动切换方向B。当前也没有解决JFI关于新颖防御的质疑。

## 2. 支撑C的证据链

1. 最主要拟议动机——原单源时间阈值被空间相关破坏——已被严格不变性命题排除。
2. 真实影响落在正常MSE、空间与条件/联合检测；其第一层数学均是标准协方差传播、Schur条件化、Gaussian检验与PSD上界。
3. 五节点MSE明显变化是建模事实；固定偏移危险并未因此产生新的防御缺口。
4. 未得到同信息、同通信与固定K/G下强简单基线无法达到的安全性质；没有理由仅凭大数值变化、噪声不确定性标题或未见精确组合就立项。
