## 辨识误差分解

令 $\bar d$ 为原 V1a 估计，$\bar d_A$ 为将既有活动分量权重归一化后的估计，$\mu_s$ 为原后验中真起点分量的均值，$d$ 为保存的真值。攻击期间有

\[
e_P=\bar d-\bar d_A,\qquad e_T=\bar d_A-\mu_s,\qquad e_F=\mu_s-d .
\]

三个误差来自非活动质量、活动起点混合和真起点下的拟合。平方和另加 $2e_P^\top e_T$、$2e_P^\top e_F$、$2e_T^\top e_F$。下面是解码量测单位的逐拍均值。首包也属于前 3 拍。JSON 包含经 $G$ 映射后的当前更新单位。

|---|---:|---:|---:|---:|---:|---:|---:|

## 离线标签反事实

**已知活动**参考在记录标记活动时使用 $\bar d_A$，停止或此前使用零补偿。**已知起点**参考在同一活动窗口使用 $\mu_s$。两者保留原参数先验、量测历史和 BF；健康轨迹的离线活动标签为始终不活动。真起点及活动标签仅用于研究诊断。

固定历史在每个时刻从实际 V1a 的上一拍状态独立替换当前补偿，健康侧也使用自身的 V1a 历史。表中危险拍数统计攻击段内累计有多少个单步反事实在当时阈值以上且尚未报警。完整闭环则让每个标签参考用原共 G 更新传播自己的状态，重新计算窗内首次危险；其危险列计路径。饱和的原输出由当前观测前缀决定，故其投影结果在两种口径一致。

## 论文贡献判断

- **A　同预算有明确的精度证据。** 在起点 7 的两组既有保留样本上，V1a 对四个饱和点的攻击段平均 MSE 更低，所估名义健康 MSE 也更低。精确等成本、起点泛化和饱和之外的成熟方法仍缺相应证据。
- **B　更及时的活动证据确有改善空间。** 活动标签贡献了两模型绝大多数净风险改善，真起点带来较小的追加收益。不稳定模型同时暴露了幅值拟合残差和个别路径提前危险的问题。
- **C　调整 V1a 的核心定位。** 将 V1a 作为低成本 A0 精度强基线。论文主张采用已有 [有限时域检测—精度边界](../JFI_live_causal_attacker_and_pre_alarm_analysis/02_窗口B严格报警前精度证书.md)，A0 反事实用来解释首包与早期证据的瓶颈。只有在合法在线信息与相同健康预算下证实可用的早期风险改善，结构补偿才有依据承担主安全方法。
