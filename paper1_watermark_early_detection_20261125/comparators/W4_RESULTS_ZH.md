# 部分边受扰时的检测与定位

**受扰边与健康边已能较可靠地区分。** 在六条已知监测链路的八种固定支持上，真实密钥匹配评分下的四分之一圈旋转取得 98.36% 至 99.27% 的前三报告受扰边检出率，精确集合识别率为 97.85% 至 99.20%。固定负耦合对应的范围为 89.36% 至 92.11% 和 84.70% 至 91.98%。四分之一圈旋转的逐边检出提高 6.79 至 9.00 个百分点，精确集合识别提高 6.85 至 13.17 个百分点。置信区间按 12 个模型、方向和起点场景分层进行路径级配对 bootstrap。

## 实验对象与判据

比较三种水印：四分之一圈旋转、冻结固定负耦合 Watson 矩阵、iid Watson 矩阵。每种均使用原四残差插件评分和真实密钥匹配评分。受扰持续 60 报文，起点 50 或 65，场景方向 0°、−45° 或 +45°，物理模型为原稳定或不稳定模型。

八种候选支持包括六个单链路支持、两条进入节点 17 的链路 {3,5}、以及分别进入节点 0 和 2 的链路 {0,1}。每格 512 条独立物理路径，每条路径在八种支持下配对回放，共 49,152 个路径—支持条件。评分器始终扫描全部六边。仅登记的受扰边接收冻结攻击，其他边保留干净报文。

“精确集合识别”是路径级事件，要求前三份受扰报文内每条受扰边都至少报警一次，且同期没有任何健康边报警。受扰边逐边检出率先在路径内对受扰边平均。健康边误报率按该支持中未受扰边统计，同时另报路径级任一健康边误报。二者没有合并为六边任一报警指标。

四分之一圈旋转匹配评分下，同期每条健康边的误报概率为 0.01% 至 0.02%。路径中至少有一条健康边误报的概率为 0.03% 至 0.08%。双边攻击比单边攻击更难得到精确集合，原因是集合事件要求两条受扰边同时检出。健康边误报仍很少，{3,5} 和 {0,1} 的精确集合概率分别为 97.87% 和 97.85%。

插件评分下四分之一圈旋转的逐边检出平均为 81.76%，精确集合平均为 79.41%。插件评分对三种水印使用相同的健康统计量。匹配评分对每种密钥族使用其冻结的独立 W1 阈值。

## 估计误差与健康风险边界

检测改善没有转化为每种支持下都更低的状态估计误差。匹配评分下，四分之一圈旋转与负耦合的直接受影响节点攻击窗 MSE 差，在六个单链路和两个双链路支持中有正有负，逐支持的 95% 配对区间均包含零。报告同时给出目标接收节点、原五个受影响节点、全网攻击窗和停止后的恢复窗 MSE，见机器表。

健康路径整段 FWER沿用 W1 独立 4096 路留出值。八种部分攻击支持不会改变健康条件下的评分分布，因而沿用在攻击结果产生前冻结的阈值。匹配评分的 W1 健康留出点估计为 4.81% 至 5.74%。该数值是全六边、k=5 至 149 的整路径任一报警概率，与本实验仅前三拍的健康边条件误报分别报告。

对四分之一圈旋转相对负耦合的精确集合识别差，单边支持为 +6.85 至 +9.03 个百分点；{3,5} 和 {0,1} 分别为 +13.17 和 +12.65 个百分点。逐支持区间为普通配对 95% 区间，未作八种支持的家族校正。结论限于原六条已知边，不涵盖未监测节点或任意开放式支持。
