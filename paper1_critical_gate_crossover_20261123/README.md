# 实验 A：关键互补链路的门控损失分解

在 35→26 唯一互补链路上，冻结的硬门控同时造成两类损失。不稳定模型中，拒绝量测本身使干净报文的估计变差，门控后残余污染产生的净 MSE 增量也高于始终接纳时的污染增量。稳定模型的连续故障中，门控减少了污染增量，但其点估计收益仍小于拒绝量测的代价。

## 四个配对对照

沿用 `78160f3` 的四维局部不可观测模型。每种动力学和固定离线故障时序复用 512 条路径，三种水印在组内共用物理路径。节点 26 的缺失块为后两个状态分量。故障期间为 $[50,110)$，故障停止后为 $[110,150)$。本文报告的是状态块平方欧氏误差的每拍均值。

在每条路径上，用原报文和原阈值重建全部七边的门控序列 $G$。与旧档逐拍核对关键链路的门控位，并重新计算其余三个已有对照的路径损失。新对照 $J_{0,G}$ 将收到的报文替换为干净报文，同时沿用完整的 $G$ 及其共 $G$ 增益模式。这里的 $0$ 表示无故障或全接纳，取决于所处下标。

| 记号 | 报文 | 接收策略 |
| --- | --- | --- |
| $J_{A,G}$ | 含固定故障 | 原检测器生成的冻结门控 |
| $J_{0,G}$ | 干净 | 同一冻结门控 |
| $J_{A,0}$ | 含固定故障 | 全接纳 |
| $J_{0,0}$ | 干净 | 全接纳 |

令 $C=J_{0,G}-J_{0,0}$ 为拒绝量测的代价，$D_G=J_{A,G}-J_{0,G}$ 为门控后污染增量，$D_0=J_{A,0}-J_{0,0}$ 为全接纳时污染增量。则每条路径上均有

$$J_{A,G}-J_{A,0}=C+(D_G-D_0).$$

$C$ 衡量把相同的删边与增益切换施加到干净报文上的联合代价。它涵盖原故障时刻丢失的假想干净观测，因此不能直接解释为实际健康报文的误拒率或代价。冻结门控来自故障轨迹，可用于离线反事实，在线无法预知该序列。 [逐路径数据](crossover.npz)

在不稳定模型的负耦合回放中，$D_G-D_0$ 在连续和突发情形分别为 **+306.96** 和 **+68.29**，未调整 95% 配对区间分别为 [167.48, 446.45] 和 [25.34, 111.24]。低接纳率仍可对应高污染损失，因为保留的扰动会经过由门控决定的后续状态更新。在稳定连续情形，$D_G-D_0=-4.97$，区间为 [−5.82, −4.12]。拒绝代价为 5.61，门控净代价的区间 [−0.14, 1.43] 跨零。 [完整摘要与配对区间](crossover.json)

在负耦合与 iid 的比较中，不稳定连续情形的总 MSE 差 +119.43 可分为拒绝代价差 +26.04 和残余污染增量差 +93.39。两项描述性区间分别为 [0.29, 51.78] 和 [−39.85, 226.64]，总差区间仍跨零。其余三个场景的总差也均跨零。故障停止后，不稳定连续情形中，负耦合的拒绝代价和残余污染增量仍分别为 38.88 和 125.18。摘要同时包含正耦合、全网指标及全部时间窗口。 [完整摘要](crossover.json)

## 残余增量为何可以超过全接纳

令 $e_{0,G}=\hat x_{0,G}-x$ 为干净冻结门控的误差，$b=\hat x_{A,G}-\hat x_{0,G}$ 为同门控下的状态位移。以 $P$ 选取节点 26 的缺失二维块，则每拍的残余增量可写为

$$\|Pb\|^2+2(Pe_{0,G})^\top Pb.$$

使用节点 26 的完整四维齐次矩阵传播 $b$，再提取缺失块。共 $G$ 聚合更新会耦合两个状态块，直接截取二维齐次矩阵会漏掉另一块对缺失块的影响。不稳定连续情形的负耦合样本中，缺失块位移能量和交叉项分别为 359.19 和 −25.70。突发情形分别为 67.47 和 +14.80。故障停止后已有污染位移仍可沿后续模式传播。反事实结果量化了硬门控的两项损失，检测器历史长度的影响留给实验 B。

## 回读与复现

实验是对旧轨迹的事后配对回放。区间以本次冻结阈值为条件，使用未经多重比较调整的配对 t 区间。新一轮独立样本、重新校准或不同故障强度都可能改变结果。完整状态与缺失块位移递推的最大差为 $8.58\times10^{-10}$，历史三组路径损失的最大复算差为 $1.14\times10^{-13}$。

在完整仓库根目录执行 `python paper1_critical_gate_crossover_20261123/run_crossover.py --output-dir <新目录>` 可重跑。执行 `python paper1_critical_gate_crossover_20261123/verify_crossover.py` 回读已保存的路径和七边门控并复算统计。需要 NumPy 和 SciPy。 [用户审阅](user_review.md) · [研究记录](dialogue.md)
