# 实时证据边界与独立配对协议

## 已验收的防御侧因果接口

接收器在第 $k$ 拍只接收至今的可信量测、实际目标报文和同步解码信息。原 BF 在未经修正的目标报文上运行。每种方法分别更新健康与受扰世界，信号评分不随方法而改写。冻结增益误差递推可用两条路径的实际动作 $c_k^a,c_k^0$ 独立核对

$
b_k=F b_{k-1}+G(z_k^a-z_k^0)-c_k^a+c_k^0 .
$

健康与受扰的 MSE 保留 $2(e_k^0)^\top b_k$ 的交叉项。两条递推的逐拍复算与旧端点回归误差保存于 [核验结果](results/delivery_checks.json)。评估保存首包全危险、首包严格报警前危险、首危险时间、首 BF 报警时间、攻击段及停止后 MSE。时标为 0 至 31，同拍报警不计严格报警前危险。

严格球的直径证明逐路径覆盖任意保持可信输入不变的目标报文，包括由历史或当前可读信息实时产生的单链路扰动。该结论不需要复现或预测具体扰动。2% 及以下成本的锚定和其他基线，其统计证据来自固定回放分布。

## 独立验证协议

- 先锁定冻结模型、接收接口、四个健康成本点、BF 阈值及危险判据，再发布每模型独立的健康校准种子及测试种子。健康校准不使用测试轨迹或风险结果。
- 测试使用新物理、解码和档案抽样种子。刺激来自独立于防御器输出的固定档案，输入对各方法配对。同一模型不同档案情形允许复用物理样本。所有方法在自己的估计历史上更新。
- 原预算 $E=10$ 检查沿用在源档案的编码域范数。危险沿用 $D=0.1$，不在解码域重定义能量。真值、未扰动目标报文及健康反事实与在线接收状态分离，用于离线计分。
- 若将来有独立外部合规测试记录，H 与 C 的区别须由发出及接收时标、可信信息隔离和第三方测试权限记录核验。H 的权限限于读取过往编码报文，C 可额外读取当前编码报文。观察者无法仅通过估计输出判断这些权限是否被遵守。外部记录的测试汇总属于记录分布上的结果。
- 任意有限选出的情形或策略族上观察到的最大风险，只属于该有限集合的评估。逐路径安全球定理是单独提供的类内上界。32 个回放比较的同时区间只对预登记回放分布解释。

本轮实时 A1-H/C 攻击策略生成与针对各防御的攻击参数优化未执行。可复验材料包含接收端因果实现、两世界配对实验和适用于严格球的逐路径证书。固定回放与实时因果验证的差别需要在稿件中保留。
