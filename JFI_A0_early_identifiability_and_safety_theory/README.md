# A0 早期可辨识性与有限时域安全理论

基线 [c050b20](https://github.com/center-666/paperlast/commit/c050b2033589868145878ff2047e733d47e68582)。本轮使用原十拍 A0、共 G、防御及既有健康模型。原 32 拍任意单包证书作为限定接收器类的已有边界引用。

**研究决定为暂缓独立投稿，保留技术底稿。** 首包难辨既有真实 Gaussian 观测重叠，也有工作先验的起点稀释与幅值失配。等成本点已能按健康名义 MSE 点估计构造。V1a 与饱和的匹配点试验仍只各使用每模型 12 条完整记录。

在完整基线树的本目录运行 Python 3.10 或更新版本。

~~~sh
python -m pip install -r requirements.txt
python -B -m unittest discover -v
python -B run_theory.py
~~~

指定另一份完整冻结树时使用 --baseline。两项入口都校验依赖和原研究输入。求根使用既有健康模型和健康条件 MSE 估计；受攻效果读取及闭环评分发生在半径确定之后。报告的解析界、条件水印经验平均与 12 条探索对照各有注明。
