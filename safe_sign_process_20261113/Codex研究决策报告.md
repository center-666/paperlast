# Codex研究决策：有条件继续

日期：2026-11-13。仅针对第一篇风险约束秘密符号时序候选。

## 1. 已通过的结构关口

- 独立整数复算安全960词，零等号边界；停止后无限尾部已补齐，共同矩阵裕度至少1/4000。
- 合法图存在470状态、912内部边的闭合不可约非周期分量；最大熵率约.965 bit/拍，支持不变的16位概率实现可运行。
- 固定LTI、单次10拍自主攻击、零进入位移及能量≤10下，任意预选或依据历史符号选择的起点均有全时域逐实现损害<D。矩阵层F/g各1e−6扰动的保守安全域非空。
- 同一检测器下，约束过程的危险先报警风险为0，而独立符号已有合法固定攻击的正风险下界；这个区别来自限制损害，不是检测率100%。

## 2. 为什么不选择“继续立项”

1. **秘密性必要性仍缺。** 公开交替周期也满足同一窄攻击族损害保证，末拍单次检测诊断甚至更好。高熵是额外结构性质，尚未证明目标安全要求一定需要它。
2. **逐拍不可预测性不成立。** 28个强制状态、已知五位同号后缀后的确定下一位必须保留。两步块随机性不能写成每拍隐藏当前符号。
3. **未知起点检测未验收。** 损害定理覆盖任意起点；现有GLRT功效表仅已知起点诊断，完整扫描、序贯总误报和泄露选择下统计模型尚未验证。
4. **工程范围仍窄。** 精确对象是冻结矩阵，1e−6为保守数学扰动域，未对应真实DARE/设备不确定性。更换L、A、F/g须重新建码本和尾部证书。
5. **文献独立性未关闭。** 动态互逆、约束切换与最坏攻击损害优化已有。不能将安全词筛选＋标准PF过程直接包装为新方法。

## 3. 后续仅保留的验证方向及停止条件

优先补具体近邻的定理级等价证据，判断它是否只是现有切换/最坏输出增益设计对有限自主族的实现。不要继续调整D/E、码本概率或检测器以追求数字优势。

若已有方法已覆盖此安全与随机性组合，或应用只需公开合法周期即可满足安全目标，则停止将其作为论文独立防御贡献。若能明确旧结果不覆盖的条件，再讨论是否需已授权范围内的未知起点统计验收；此处没有预先授权新算法或大规模实验。

## 4. 对最终问题的回答

**在本轮明确的固定模型、原单次自主攻击族、零进入位移和理想同步假设下，答案是可以。** 可以在每拍通信负载及编码幅值不增加时，用合法高熵符号时序获得未知起点的逐实现危险位移保证，并保留预定FDI的检测几何。

但尚不能答“已保留充分的未知起点在线检出率”或“已具可投稿独立创新”。本次是结构可行性成果，进入有条件继续状态。
