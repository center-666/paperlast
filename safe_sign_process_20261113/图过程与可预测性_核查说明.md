# 安全词图、最大熵过程与可预测性

日期：2026-11-13。输入为主过程本轮从冻结十进制模型独立复算的`safe_words.json`，不是直接沿用旧JSON的分类。输出见`graph_process.py`与`graph_results.json`。本文件只完成序列图与随机过程部分；输入码本的停止后无限尾部保证由主报告另证。

## 1. 有限图及无限生成

将−1记为0、+1记为1，九位历史编码为整数0…511；十位词编码为0…1023。对每个严格安全词w，边为`(w>>1)→(w&511)`。边的生成是精确的整数操作。

新安全集合960词给出512状态、960边的图，43个强连通分量。唯一含有向循环的分量有470状态、912内部边，周期gcd=1。其余42分量是无自环单点。全图中有10个无后继状态、44个一个后继状态、458个两个后继状态；496个状态可以沿某条有限路径进入唯一循环分量，另16个不具无限延伸路径。

因此不能从“每个局部词安全”推出“任意九位初始化都能永久生成”。明确的实现方式是：收发端从470状态分量中的同一状态初始化，此后仅采用其912条内部边。每个状态至少一个后继，任何内部转移都保持在该分量，故可无限生成且每个连续十位词都安全。图中一条显式循环为16→33→66→132→264→16；全部强连通性及周期判据由完整边集核查。

有限图的邻接矩阵A满足：长度n允许路径数量按`ρ(A)^n`的指数阶增长，所有循环分量中的最大谱半径给出拓扑熵。此处只有一个循环分量，故全图拓扑熵由该470状态分量决定。

## 2. Perron最大熵Markov链

对470状态内部邻接矩阵A，取正Perron左右向量r、l，使`Ar=ρr`、`lᵀA=ρlᵀ`及`lᵀr=1`。定义

\[
P_{ij}=\frac{A_{ij}r_j}{\rho r_i},\qquad \pi_i=l_ir_i.
\]

因为`Σ_j A_ij r_j=ρr_i`，P逐行和为1；由左右特征方程可得`πᵀP=πᵀ`。所有内部边转移概率严格正，且该图不可约、非周期，故存在唯一正平稳分布。用π初始化即为平稳过程；任意内部初态也有相同极限分布，但启动阶段不能声称已平稳。

其熵率为

\[
-\sum_i\pi_i\sum_jP_{ij}\log_2P_{ij}=\log_2\rho.
\]

证明：在允许边上`log P_ij=log r_j−log r_i−logρ`，平稳性使两个r项抵消。对任意同支持平稳Markov链Q，转移相对熵非负给`h(Q)≤log₂ρ`；故该链达到图的最大熵。此为标准Perron–Frobenius/有限型符号动力系统构造，不列为本研究独有方法。

数值复算：

- `ρ≈1.9520978299132081`；`log₂ρ≈0.9650253557665646 bit/拍`。
- 熵率直接按π、P求和为0.9650253557665643，相差约3×10⁻¹⁶。
- 以浮点r的十进制表示作为严格正有理测试向量，再精确计算各行`(Ar)_i/r_i`，Collatz上下界为
  `18400583150014401/9426055840056197 ≤ ρ ≤ 17187813877863471/8804791242776830`，宽约2.73×10⁻¹⁵。

后一个谱半径外包是有理不等式证书；r、l、π、转移概率和显示的熵值仍为浮点结果。完整状态列表、912条P、π、全图960边及全部SCC都在JSON，便于独立复算。

## 3. 平衡边缘与可预测性

安全图及循环分量在整体符号翻转`i→511−i`下不变。不可约最大熵平稳测度唯一，故翻转后的过程具有同一测度；由此每拍`P(s_t=+1)=P(s_t=−1)=1/2`且`E s_t=0`。浮点复核得到+概率0.49999999999999994、均值约−1.1×10⁻¹⁶。**无偏边缘不表示跨时刻独立。** JSON另给完整十位词平稳概率`π_source P_edge`及十拍符号相关矩阵。

循环分量内部有28状态唯一后继，平稳质量约2.5392548224%。这些状态的下一位条件熵恰为0、最佳预测概率恰为1。不存在逐拍统一的正条件熵下界。最坏历史可预测与整体熵率0.965并不矛盾。

不存在连续两步都被迫转移的状态链，最长强制链为1步。已知当前状态时，未来第二位的最坏最佳预测概率约0.671736，未来第十位约0.504593；猜中未来整个十位词的最坏条件概率约0.00264991。这些为该PF链的数值结果，不是对任何秘密实现或任意泄露模型的密码安全证明。

图含周期路径，但分量周期为1、平稳链非周期；“存在循环”不等于“生成过程只有周期”。理想正熵转移下，某条特定无限周期路径的概率为0。相反，若仅秘密选择一个有限周期然后重复，则未来可以被识别，不能用上述熵率证明其安全。

## 4. 有限精度及同步实现

无需精确存储无理Perron概率才能保持安全。JSON给出一个支持完全不变的16位二进制概率近似：每个双后继状态的第一转移概率为`n_i/65536`（四舍五入并夹在1…65535），另一条为其补；单后继状态概率1。该有理链仍不可约非周期，符号翻转对称性用整数分子逐边核对，安全支持没有增加。

其数值熵率约0.9650253557048969，最大转移误差约7.58×10⁻⁶；不称它精确达到最大熵。最大分支概率的精确分数为43842/65536。由于任何连续两次转移至少有一次分支，猜中任意两位未来块的最大条件概率≤43842/65536<1；这是一个与单拍强制状态相容的较粗块随机性保证。

收发双方共享图版本、当前九位状态、时钟/报文epoch和逐时刻随机输入。可每个时钟消耗一个秘密16位均匀整数，按相同有理阈值选边；即使状态强制，也消耗相同索引的随机数以免丢包或跳步导致序列偏移。需在**发送时刻**而非收到的包数上更新状态；丢包后的恢复依赖可信epoch或显式重同步。此处没有设计认证协议及相应成本。

采用理想无限独立秘密随机输入，才有上述信息论正熵率；单个有限PRNG种子驱动的无限确定序列，其信息论熵率为0，实践可讨论计算不可预测性但不能以此PF熵值替代密码分析。16位实现例的原始秘密输入开销为16 bit/拍，而符号输出熵约0.965 bit/拍；这不是额外无线报文，但确实有密钥/随机源、存储与同步成本。

初始化可从π采样内部状态（精确平稳理论），或选择任意共享内部状态（启动非平稳但局部词仍安全）。用浮点π近似采样只近似平稳，安全性不受影响。若攻击者知道历史符号，他可以识别九位状态；秘密初始状态并非永久安全来源，理想新转移随机数也不能在强制状态创造不存在的单拍熵。

## 5. 本项决定

无限可延伸性与正熵率通过限定结构核查；逐拍不可预测性不成立。该图提供可实现的安全支持随机过程，但是否构成第一篇的独立防御贡献，还依赖尾部安全、攻击权限、鲁棒性和文献排重。图本身的正熵率和Perron构造不单独通过投稿验收。
