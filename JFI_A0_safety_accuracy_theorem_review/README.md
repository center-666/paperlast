# 十拍 A0 有限时域安全—精度理论审查

冻结基线为 [e9ec9e2](https://github.com/center-666/paperlast/commit/e9ec9e22f04ea10c0bd3a14b11c60b31ccf1cda8)。使用现有五节点模型、原 BF、共 G 接收器、十拍固定模板及已有归档。归档核查沿用相同输入和原 Sobol 节点。

**决定为 CONDITIONAL GO。** 参数化定理成立于共享可信参考、临界等号横向非集中，以及存在严格未报警的反向共线支持点的模型类。最后一项同时约束可达估计位移与原 BF 停止时刻。定理包含超出球直径充分性的反向结论，支持继续组织第四章。现有证据尚不足以确认独立投稿。

## 复算

在此目录运行，或用 `--baseline` 指向具有完整冻结数据的研究树。使用 Python 3.10 与 [依赖版本](requirements.txt)。`--health-only` 运行健康代价计算与曲线，完整运行还包括四维首包盒积分与归档核对。

```text
python -B -m unittest -v
python -B health_cost_analysis.py --health-only
python -B health_cost_analysis.py
```

54 项输入在计算前后核对 SHA-256。审计前逐项与冻结提交的 Git blob 比对。完整运行输出 [认证与统计结果](results/results.json) 及 [健康成本曲线](results/health_cost_curve.svg)。附 [执行日志](results/run_log.txt) 与 [单元测试日志](results/test_log.txt)。
