# 最小可执行协议与检验

protocol.py新建于本目录，不修改run_common。顺序记录：旧判决到达→物理采集→编码与标签→攻击者按合法视图决定→当拍验证/排队→解码或缺失→原量测统计检测→原共G更新→实时发布。

理想认证是进程内不可伪造token与不可变字段绑定，验证器只返回Boolean。测试后端存储绑定是理想oracle实现，不是接收端可读干净副本；没有从该后端取得替代量测。它不是实际MAC实现、密码学证明或硬件测速。

支持无验证、全及时、公开偶数时刻、私有接口的支持内5次、全报文晚1拍及晚2拍。私有用例仅检查API不把安排传入攻击器；回归pattern公开可复算，不证明部署中的秘密性。真正独立私有抽样是04的理论假设，本轮未实现秘密调度生成、密钥同步或新的概率实验。原A0、H/C旧谱波形、全能量OL首包、极小篡改和显式时序约束C波形共同测试；不扩角度/参数网格，不把时序约束波形叫原自主A0。

AttackView只含k、过去q、授权的当前q和可公开安排；没有真实状态、M、认证判决或密钥。H调用时当前q参数为None，动作后才将该包加入历史。实际执行总预算含被拒包，不按解码能量计。

认证失败：当拍完整删除目标创新，其他邻居及K/G保持；迟到失败只将过去载荷标为不可用于后续检测窗口，历史输出/报警记录不改。本轮无统计报警后隔离或重接纳算法，因此整个31拍MSE是该明示策略的结果，不能称已验收的报警恢复闭环。

|测试安排（32拍）|发送标签数|接收验证数|及时保护数|是否新增量测等待|
|---|---|---|---|---|
|无验证|0|0|0|否|
|公开偶数拍验证|16|16|16（攻击支持内5）|理想判决在期限内|
|私有支持内5次|32|5|5|理想判决在期限内；全包标签隐藏检查安排|
|全部及时|32|32|32|理想判决在期限内|
|全部晚1/2拍|32|32|0|先发布；不能把它计为及时保护|

两个原检测器分别使用各自5%有限事件Bonferroni阈值；每个风险单独计算，不能OR后还叫5%。认证失败另记τ_auth。缺失窗口直接跳过，不把零向量当健康量测；正常无攻击时所有包通过，原28窗FA界保持。受攻选择后的窗口分布不预设Gaussian。

本轮911项检查、140组有限协议用例通过，复用两模型各2条旧物理输入；没有新增随机样本、训练/独立验证集或概率估计。

检查包括：理想同步无攻击等于原共G；修改载荷/时间戳/收件人/epoch拒绝；合法未改通过、重放拒绝；动作因果及能量；两世界切换身份；其他四节点不被目标估计多跳污染；每拍恰一次输出；全认证的严格先报警事件为空；迟到输出与同输入无验证输出相同；不访问私有安排；原参考字节一致。
