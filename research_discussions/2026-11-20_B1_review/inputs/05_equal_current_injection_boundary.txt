我们继续往下推导。这次我想先解决一个决定B1能否成立的数学问题。

**两种攻击起点不同、已经造成不同历史状态污染，是否意味着下一拍主动水印能够帮助区分它们？**

答案是：**不一定。而且在原模型一致性攻击下，存在一类非常重要的情况：即使两种攻击造成了不同的历史估计偏移，下一拍水印也无法增加它们之间的辨识信息。**

这个结论对我们选择新的信息获取算法非常关键。

# **一、从两个攻击起点开始分析**

保留接收节点1、目标链路 \\(0\to1\\) 和原共G估计器。

考虑两个候选攻击解释：

\\[ \begin{aligned} h_1 &: \tau_1=k-1,\quad \xi=\xi_1,\\\ h_2 &: \tau_2=k,\quad \xi=\xi_2. \end{aligned} \\]

即第一种攻击在上一拍开始，第二种攻击在当前拍开始。

在第 \\(k\\) 拍，两种解释对应的编码域攻击分别为：

\\[ a_k^{(1)}=H_0A\xi_1,\qquad a_k^{(2)}=H_0\xi_2. \\]

定义它们的当前攻击差异：

\\[ \boxed{d_k=H_0A\xi_1-H_0\xi_2.} \\]

接收端为当前拍选择一个秘密水印矩阵 \\(M_k\\)。

## **1. 两种假设的当前观测差异**

根据原编码和解码机制：

\\[ y_k^{a,(i)}=y_k^0+M_ka_k^{(i)}. \\]

因此，在相同物理量测实现下，两种解释产生的受检报文差异为：

\\[ \boxed{ \Delta y_k^a=M_kd_k. } \tag{1} \\]

这意味着：

**下一拍水印能否产生新的区分信息，首先取决于两种攻击在当前编码域是否存在差异。**

如果：

\\[ d_k=0, \\]

那么：

\\[ M_kd_k=0 \\]

对任意可逆水印都成立。

不管我们如何调整水印方向、幅值或随机分布，两种假设在当前时刻施加的攻击污染都是相同的。

但是，这并不意味着两种攻击造成的历史状态损害也相同。

## **2. 两种假设的状态污染差异**

令 \\(F\\) 为原共G估计器的固定闭环误差传播矩阵，\\(G\\) 为目标链路对应的共G增益。

两种假设的当前累计偏移分别为：

\\[ b_k^{(1)} = FGM\_{k-1}H_0\xi_1 + GM_kH_0A\xi_1, \\]

\\[ b_k^{(2)} = GM_kH_0\xi_2. \\]

所以：

\\[ \boxed{ \Delta b_k = FGM\_{k-1}H_0\xi_1 + GM_kd_k. } \tag{2} \\]

现在考虑：

\\[ H_0A\xi_1=H_0\xi_2. \\]

那么：

\\[ \boxed{ \Delta b_k = FGM\_{k-1}H_0\xi_1. } \tag{3} \\]

也就是说：

- 当前受检攻击增量相同；
- 两种假设的历史污染不同；
- 当前水印 \\(M_k\\) 无法改变两种假设之间的状态偏移差异。

这个现象说明：**历史污染存在差异，并不自动意味着当前水印有能力主动探测这种差异。**

假设 \\(h_1\\)

上一拍已攻击

存在历史偏移

\\(\displaystyle b\_{k-1}^{(1)}\ne0\\)

假设 \\(h_2\\)

当前拍才攻击

此前无攻击偏移

\\(\displaystyle b\_{k-1}^{(2)}=0\\)

**当前攻击增量相同**

\\(\displaystyle a_k^{(1)}=a_k^{(2)}\\)

当前水印不能放大两者之间不存在的攻击增量差异

**历史状态污染仍然不同**

\\(\displaystyle \Delta b_k=F\Delta b\_{k-1}\\)

区分失败可能导致不同的状态修正决策

需要补充一个严格的区别：历史受检观测与当前健康噪声可能相关，因此当前数据仍可能帮助推断过去的攻击起点。但在以上两种假设的当前攻击增量相同时，这部分额外辨识能力来自物理过程的时间相关性，而不是对 \\(M_k\\) 的主动选择。

这已经给B1划出了一条重要边界。

# **二、把上述现象推广成一个“主动信息获取可行性判据”**

前面是比较具体的攻击偏移。现在把观测的统计相关性也纳入进来。

令 \\(\mathcal F\_{k-1}\\) 表示当前水印选取前，接收端合法掌握的全部历史信息。

对于两个固定攻击假设 \\(h_1,h_2\\)，在条件线性Gaussian模型下，下一拍接收数据的预测分布可以写成：

\\[ z_k\mid h_i,\mathcal F\_{k-1},M_k \sim\mathcal N(\mu_i(M_k),S_k). \\]

这里可以将当前可信节点量测一起纳入 \\(z_k\\)；如果只保留目标链路，以下公式中的水印作用矩阵就是单位矩阵。

两个假设的预测均值差能够写成：

\\[ \boxed{ \Delta\mu_k(M_k) = r_k+E_kM_kd_k. } \tag{4} \\]

其中：

- \\(r_k\\)：由过去不同的攻击解释引起的预测差异，包括历史量测与当前物理过程之间的相关性；给定设计历史后，它不依赖尚未选择的 \\(M_k\\)。
- \\(d_k\\)：两种假设当前编码域攻击的差异。
- \\(E_k\\)：将受检量测污染嵌入当前联合观测向量的已知矩阵。

假设两者具有相同的条件协方差 \\(S_k\succ0\\)。

则可以定义：

\\[ \boxed{ s_k(M_k)= \Delta\mu_k(M_k)^\top S_k^{-1} \Delta\mu_k(M_k). } \tag{5} \\]

对于这两个已知参数的Gaussian假设：

\\[ D\_{\mathrm{KL}}(P_1\\|P_2)=\frac12s_k(M_k). \\]

于是，我们得到第一个可以明确使用的结论。

**命题1：当前水印的信息作用边界**

如果：

\\[ d_k=0, \\]

则：

\\[ s_k(M_k)=r_k^\top S_k^{-1}r_k, \\]

与当前水印选择无关。

也就是说，当前水印无论如何设计，都无法提高这两个固定假设在下一条观测上的区分度。

如果 \\(r_k\neq0\\)，新观测仍然可能提供信息；但这种信息来自历史物理状态和噪声的条件相关性，而不是当前水印优化。

这个结论有一个重要限制：它针对固定攻击参数和共同条件协方差的模型。对于未知连续攻击参数，不同水印可能改变公共干扰参数的估计质量，因而不能直接将命题推广成所有复合假设下的不可能性结论。

## **三、当&#x20;**\\(d_k\neq0\\)**&#x20;时，究竟应该怎样选择水印？**

这才是B1真正有优化空间的情况。

我们不仅需要考虑观测区别：

\\[ s_k(M_k), \\]

还要考虑两种攻击解释的状态污染差：

\\[ \Delta b_k(M_k) = b_k^{\mathrm{past}}+GM_kd_k. \\]

其中：

\\[ b_k^{\mathrm{past}}=F\Delta b\_{k-1}. \\]

现在定义状态污染差异的平方权重：

\\[ H_k(M_k) = \\|\Delta b_k(M_k)\\|\_W^2, \qquad W\succeq0. \\]

### **一个比KL更合理的目标**

设两种假设在当前设计历史下的先验概率分别为 \\(\pi\\) 和 \\(1-\pi\\)。

在收到新观测以后，两种假设的后验概率会变化。

记：

\\[ \eta\_\pi(s) = \mathbb E\big[p_k(1-p_k)\big], \\]

其中期望针对两假设混合预测分布，\\(p_k\\) 是收到新观测后的第一假设概率。

对于共同协方差Gaussian双假设，\\(\eta\_\pi\\) 可以由一维Gaussian积分计算，并且随观测区分度 \\(s\\) 增大而非增。

那么当前**两假设状态污染混淆风险**为：

\\[ \boxed{ \mathcal R_k(M_k) = H_k(M_k)\\, \eta\_\pi(s_k(M_k)). } \tag{6} \\]

这个式子可以视为我们B1设计的核心。

因为水印同时影响：

\\[ \underbrace{H_k(M_k)}\_{\text{判断错误的状态损害}} \\]

以及：

\\[ \underbrace{\eta\_\pi(s_k(M_k))}\_{\text{攻击假设尚未区分的程度}}. \\]

所以水印设计不能只最大化KL。

它必须兼顾：

**水印使攻击更容易区分的收益，以及水印对实际状态污染的直接放大。**

## **四、进一步得到一个局部设计条件**

假设我们对某个候选水印 \\(M\\) 施加小扰动：

\\[ M\mapsto M+\epsilon U. \\]

暂时不考虑水印矩阵可行域限制，先研究风险如何变化。

由式(6)得到：

\\[ \mathrm d\mathcal R = \eta\_\pi(s)\\,\mathrm dH + H\eta\_\pi'(s)\\,\mathrm ds. \\]

其中：

\\[ \mathrm dH = 2\Delta b^\top WG\\,U d_k, \\]

\\[ \mathrm ds = 2\Delta\mu^\top S_k^{-1}E_kU d_k. \\]

所以：

\\[ \boxed{ \begin{aligned} D\mathcal R(M)[U] ={}&2\eta\_\pi(s) \Delta b^\top WG\\,U d_k\\\ &+2H\eta\_\pi'(s) \Delta\mu^\top S_k^{-1}E_kU d_k. \end{aligned} } \tag{7} \\]

这两个部分的意义非常清楚。

| 项   | 物理意义            | 设计目标           |
| --- | --------------- | -------------- |
| 第一项 | 水印改变两种假设的状态损害差异 | 尽量减少错误决策的后果    |
| 第二项 | 水印改变两种假设的可区分性   | 尽量减少错误决策发生的可能性 |

这里第二项中的 \\(\eta\_\pi'(s)\le0\\)，说明增加区分度通常有助于降低混淆风险。

但第一项可能为正。

所以**主动水印增加信息，不一定降低最终估计风险**。

当 \\(d_k=0\\) 时，两项均为零。这与前面的信息作用边界完全一致。

对于 \\(d_k\neq0\\)，如果存在满足资源和秘密性约束的合法水印变化方向，使式(7)严格为负，那么可以在该双假设工作模型下实现局部混淆风险改善。

但这只是可行性条件。将它转化为实际的随机水印分布，还需要计算我们之前提出的四阶方向敏感度，并检查条件平均编码资源。

# **五、这个结论揭示了B1的真正难点**

我认为这里需要重新评价之前的研究设想。

我们原本希望：

> 不同攻击起点造成不同历史污染，所以可以通过下一拍主动水印提高辨识。

但现在证明，这个推理缺少了一个必要环节。

**下一拍水印只能直接作用于当拍编码域攻击。它不能重新调制已经进入估计器的历史污染。**

如果两种假设当前编码域攻击相同，那么即使历史损害差异很大，主动改变当前水印也没有新的假设区分作用。

以最简单的情形说明：

\\[ A=I,\qquad \xi_1=\xi_2=\xi. \\]

在两段长度相同、相互错开一拍的攻击共同持续期间：

\\[ a_t^{(1)}=a_t^{(2)}=H_0\xi. \\]

因此，两种攻击的当拍污染相同。

但由于较早攻击多作用了一拍，它们的状态估计偏移仍然不同。

只要在该区间内维持同样的编码域攻击，新增水印就不能制造两种假设当前不存在的差异。

它们仍可以通过历史观测被辨识，也可能在攻击停止时间不同后产生新的观测区别，但**不能把这些收益归功于共同持续期间的当前水印选择**。

这不是说B1完全不可行，而是说明：

**B1只能利用已有攻击假设之间在未来通信输入上的差异，不能主动创造新的物理观测信息。**

# **六、我们该如何据此修改算法？**

我不建议再将所有攻击假设等价地送进一个水印优化器。

而是先增加一个**可主动辨识性分析层**，让算法判断哪些攻击差异确实能够被下一拍水印影响。

具体可以分为三个类别：

| 攻击假设对 | 当前攻击差异                   | 水印应该怎么做               |
| ----- | ------------------------ | --------------------- |
| 第一类   | \\(d_k=0\\)              | 不浪费资源主动区分；依赖历史信息和可信量测 |
| 第二类   | \\(d_k\neq0\\)，但状态污染差异很小 | 不优先分配辨识能力             |
| 第三类   | \\(d_k\neq0\\)，且状态污染差异很大 | 优先考虑主动水印，提高任务相关信息质量   |

这样，算法才有真正明确的信息获取策略。

在每拍开始前，我们可以先构造：

\\[ \mathscr P_k = \left\\{ (h_i,h_j): \\|d\_{ij,k}\\|>0,\  \\|\Delta b\_{ij,k}\\|>\gamma \right\\}. \\]

其中 \\(\gamma\\) 是预先规定的状态损害重要性门槛，而不是通过真实攻击标签调出来的数值。

然后只对其中有主动辨识潜力的假设对，计算式(6)和式(7)描述的风险。

需要特别注意：**对于第一类不可主动区分的假设，不能简单从鲁棒风险中删除。** 它们仍然可能是最危险的假设，必须在最终融合器中保留。

这就形成一个更完整的分工：

\\[ \boxed{ \begin{aligned} &\text{水印：主动区分可受影响的危险假设};\\\ &\text{可信量测：提供独立状态信息};\\\ &\text{鲁棒融合：处理仍不可区分的危险污染}. \end{aligned} } \\]

## **七、从研究创新性看，我现在更倾向一个调整**

原B1主要研究：

**历史条件化水印方向分布。**

现在我认为，若要将它作为JFI论文的中心贡献，需要进一步提出：

**状态污染可辨识性驱动的主动信息获取机制。**

其目标不应局限于调整四阶方向分布，而应先识别：

\\[ \ker(\text{未来观测差异}) \\]

中哪些方向仍然造成不同的状态估计污染。

这可以进一步提出一个问题：

\\[ \boxed{ \begin{gathered} \text{当未来受检报文无法提供足够区分信息时，}\\\ \text{能否通过改变通信交互协议，主动获得新的独立约束？} \end{gathered} } \\]

如果答案是肯定的，那么我们就从B1自然走向B2：**主动挑战式信息获取**。

例如，要求可信发送节点针对同一个保存量测执行额外的秘密编码挑战，或者调度额外的可信观测以约束攻击参数。

但是，这涉及额外通信成本和信任假设。尤其当发送端可信、网络允许认证通信时，还必须与标准消息认证方法比较，不能用一个本来可以直接保护报文完整性的安全信道来包装新的水印检测优势。

因此，B2也不是天然更有创新性，只是它可能真正改变原有问题的信息结构。

## **八、我的阶段判断**

通过这一步推导，我对B1的评价更加明确了。

**它是一条数学上可以定义、可以优化的算法路线，但目前不足以成为我们已经确定的最终方法。**

核心原因不是优化太难，而是：

**在原模型一致性攻击下，不同起点可能产生相同的未来编码域注入。仅改变当前水印，无法主动区分这一类假设造成的历史污染。**

所以我建议先不继续扩展四阶水印分布优化，也不着急转去实现B2。

我们应该先决定一个更根本的设计选择：

**新信息获取算法，是继续限定为“只改变水印编码”，还是允许接收端与可信发送端建立具有有限额外通信开销的主动交互？**

如果严格保持原通信协议，B1的自由度有限，论文需要从可辨识性结构和安全融合性能上寻找真正增量。

如果允许受限主动交互，那么我们可以设计新的信息获取机制，尝试获得原水印编码根本无法提供的约束。

我的倾向是：**保留原模型一致性攻击和共G估计器，但允许研究受约束的主动信息获取协议。** 这有机会真正形成区别于旧式随机水印检测的新方法；当然，必须正面处理额外资源与认证通信基线。

下一步最值得讨论的，便是如何在**不直接增加可信物理传感器、不改变估计器基础结构**的前提下，使发送端和接收端通过可实施的受限交互，获取原单包水印无法获取的攻击信息。
