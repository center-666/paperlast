## 复算

先安装`requirements.txt`中依赖，Python3.10以上。在本目录执行：

```
python joint_screen.py
python detector_diagnostics.py
python independent_math_and_reentry.py
python certify_joint_reentry.py
python audit_saved_trajectories.py
python build_reports.py
```

`prepare_protocol.py`用于本次一次性注册，已有registration时拒绝覆盖，不是日常复算步骤。参考实现及旧样本库分别从相邻`common_g_reference_revision_20261115/`、`attack_gain_switch_audit_20261115/`只读取得。完整库只在私有工作区；公开复算不需下载论文。原样本256条复用，新物理随机实现0；网格按72方向/案最小检查，无50节点实验，无新检测/融合算法开发。
