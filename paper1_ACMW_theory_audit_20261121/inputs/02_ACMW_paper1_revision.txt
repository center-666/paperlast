# **二、我提出的新方案：多维角度耦合乘性水印**

已完成多维理论构造

2. 不容易直接推广到任意测量维数。

因此，我把它升级为：

**ACMW：Angular-Coupled Multiplicative Watermark（角度耦合乘性水印）。**

核心思想：

**保持每一拍水印的 Gaussian 分布完全不变，只改变不同时间水印向量之间的方向关系。**

## **2.1 水印生成机制**

将随机向量分解为：

\\[ \beta_k=r_ku_k \\]

其中：

\\[ u_k\in\mathbb S^{m-1},\qquad \\|u_k\\|=1 \\]

\\[ r_k^2\sim\sigma\_\beta^2\chi_m^2 \\]

半径序列独立生成。

方向采用一个带独立刷新机制的球面 Markov 转移核：

\\[ \boxed{ g\_{\kappa,\rho}(v|u) = (1-\rho)+ \rho\frac{\exp[-\kappa(u^\top v)^2]} {Z_m(\kappa)} } \\]

这里：

\\[ Z_m(\kappa)= {}\_1F_1\left(\frac12;\frac m2;-\kappa\right) \\]

参数含义：

- \\(\kappa\\)：控制相邻方向排斥强度。
- \\(\rho\\)：控制执行方向耦合的概率。
- \\(1-\rho\\)：独立刷新概率。

最终：

\\[ \boxed{ M_k=\lambda I_m+r_k^2u_ku_k^\top } \\]

**水印生成流程**

**生成上一拍方向&#x20;**\\(u\_{k-1}\\)

**方向耦合**

概率 \\(\rho\\)

抑制方向重复

**独立刷新**

概率 \\(1-\rho\\)

重新采样方向

**独立生成 Gaussian 半径&#x20;**\\(r_k\\)

**生成&#x20;**\\(\beta_k=r_ku_k\\)

**生成&#x20;**\\(M_k=\lambda I_m+\beta_k\beta_k^\top\\)

**原有编码、传输、解码及分布式估计器**

## **2.2 最重要的性质：单拍分布完全不变**

因为方向转移核具有旋转不变性，均匀球面分布是它的平稳分布。

再结合独立 Gaussian 半径，可以得到：

\\[ \boxed{ \beta_k\sim\mathcal N(0,\sigma\_\beta^2I_m) } \\]

这对每一个时刻都严格成立。

因此：

\\[ E[M_k]=(\lambda+\sigma\_\beta^2)I_m \\]

而且：

\\[ M_k^{-1} = \frac1\lambda \left( I_m- \frac{\beta_k\beta_k^\top} {\lambda+\\|\beta_k\\|^2} \right) \\]

仍然只需要 \\(O(m^2)\\) 的计算量。

这意味着：

**我们没有通过增加水印强度、改变单拍分布或者增加通信带宽来取得优势。我们改变的是水印的时间统计结构。**

这也是与原稿最容易进行公平对比的地方。

# **三、真正值得写入论文的理论：跨拍协方差**

这是这轮最重要的推导。

原稿中的独立 Gaussian 水印，在推导攻击残差协方差时利用了不同时间水印之间的独立性。

现在我们取消这个假设。

令：

\\[ X_k=(\beta_k^\top\delta_k)\beta_k \\]

水印作用后的攻击残差为：

\\[ \Delta r_s= \sum\_{\ell=0}^{s}Z\_{s,\ell}X\_\ell \\]

这里 \\(Z\_{s,\ell}\\) 是原奇偶矩阵对应的时间块。

单拍边缘不变，所以：

\\[ E[X_k]=\sigma\_\beta^2\delta_k \\]

以及：

\\[ \boxed{ C\_{kk} = \sigma\_\beta^4 \left( \delta_k\delta_k^\top+ \\|\delta_k\\|^2I_m \right) } \\]

这一项与原稿完全一致。

真正发生变化的是：

\\[ C\_{\ell r} = \operatorname{Cov}(X\_\ell,X_r), \qquad \ell\ne r \\]

我已经利用球面分布的四阶矩推导出：

\\[ c_h=E[(u_k^\top u\_{k+h})^2] \\]

令：

\\[ \zeta_2= \frac{c_1-1/m}{1-1/m} \\]

则：

\\[ c_h= \frac1m+ \left(1-\frac1m\right)\zeta_2^h \\]

进一步定义：

\\[ b_h=\frac{c_h-1/m}{(m-1)(m+2)} \\]

可以得到：

\\[ \boxed{ \begin{aligned} C\_{\ell r} ={}&\sigma\_\beta^4m^2b_h \bigg[ (\delta\_\ell^\top\delta_r)I_m\\\ &+\delta_r\delta\_\ell^\top -\frac2m\delta\_\ell\delta_r^\top \bigg]. \end{aligned} } \\]

因此，整个奇偶残差协方差变成：

\\[ \boxed{ \begin{aligned} C_s={}& \sum\_{\ell=0}^{s} Z\_{s,\ell}C\_{\ell\ell}Z\_{s,\ell}^\top\\\ &+ \sum\_{\ell\<r} \left( Z\_{s,\ell}C\_{\ell r}Z\_{s,r}^\top + Z\_{s,r}C\_{\ell r}^\top Z\_{s,\ell}^\top \right). \end{aligned} } \\]

这条公式是第一篇论文修改的核心。

它明确指出：

- 单拍水印协方差不变；
- 跨拍协方差出现新的非零项；
- 新水印的作用取决于攻击序列在不同时间的方向关系，以及奇偶矩阵各时间块的几何结构。

当 \\(\kappa=0\\) 或 \\(\rho=0\\) 时，所有跨拍协方差恢复为零，严格退化为原来的独立水印方案。

这使得新旧方法之间有一个非常清晰的数学连接。

## **4.1 新的协方差下界**

注意：

\\[ R_k^2\sim\sigma\_\beta^2\chi_m^2 \\]

因此：

\\[ \operatorname{Var}(R_k^2)=2m\sigma\_\beta^4 \\]

尽管方向 \\(u_k\\) 之间存在相关性，半径仍然独立。

给定所有方向 \\(U=(u_0,\ldots,u_s)\\)，利用全协方差公式：

\\[ \operatorname{Cov}(\Delta r_s) \succeq E[\operatorname{Cov}(\Delta r_s|U)] \\]

再利用均匀球面上的四阶矩：

\\[ E[(u^\top\delta)^2uu^\top] = \frac{ \\|\delta\\|^2I_m+2\delta\delta^\top }{m(m+2)} \\]

得到：

\\[ \boxed{ C_s\succeq \frac{2\sigma\_\beta^4}{m+2} \sum\_{\ell=0}^{s} Z\_{s,\ell} \left( \\|\delta\_\ell\\|^2I_m+ 2\delta\_\ell\delta\_\ell^\top \right) Z\_{s,\ell}^\top } \\]

这个结果非常重要。

它说明，即使水印方向存在时间相关性，攻击残差协方差仍然有一个严格正定意义下的下界。

在原稿相应的 \\(c_Z>0\\) 条件下，可以进一步得到：

\\[ \operatorname{tr}(\Theta_s^{-1}C_s) \ge \frac{2c_Z\sigma\_\beta^4}{m+2} \\|\Delta Y\\|^2 \\]

结合 Gaussian 最大熵性质，可以继续得到：

\\[ \boxed{ E\\|\Delta Y\\|^2 \le \frac{m+2}{2c_Z\sigma\_\beta^4}M\_\theta } \\]

其中：

\\[ M\_\theta=s_r f^{-1}(2\theta/s_r) \\]

\\[ f(t)=t-\log(1+t) \\]

因此：

\\[ E\\|\Delta Y\\|^2=O(\sigma\_\beta^{-4}) \\]

**原论文关于严格隐蔽攻击可检测性和可容许攻击能量随水印强度增加而下降的主结论仍然可以保留。**

不过，新下界的常数更保守。不能声称我们在渐近阶数上超过了原方法。

真正要争取的优势是：在有限水印强度、有限检测窗口下，通过跨拍协方差设计改善实际 KL 检测性能。

# **九、下一步我建议这样推进**

目前理论和多维解析实验已经有了初步结果，但还不能直接修改论文后投稿。接下来必须回到原来的50节点网络。

我建议分成三个实验阶段。

**阶段一：原系统复现与水印替换**

下一步优先执行

- 保留原来的50节点网络。
- 保留原来的状态维数和量测矩阵。
- 保留原来的严格隐蔽 FDI 攻击。
- 只替换 iid 水印生成器。
- 对比 \\(\kappa=0,0.5,1,2,4\\)。

评价：KL、FPR、FNR、检测延迟、攻击期间 RMSE。

**阶段二：多维扩展**

- \\(n=4,m=2\\)
- \\(n=4,m=3\\)
- \\(n=4,m=4\\)
- \\(n=6,m=2,3,4\\)

重点考察水印参数是否需要随测量维数变化，以及最坏攻击方向是否发生变化。

**阶段三：水印设计优化**

联合优化：

\\[ (\kappa^\star,\rho^\star) \\]

在相同单拍边缘、健康估计精度和统计依赖预算下，寻找有限窗口 KL 最大的水印。

还有一个必须提前处理的安全问题：原稿假设攻击序列与窗口内实际水印实现独立。现在水印具有时间相关性，如果攻击者能够观察历史水印或从报文中推断历史水印，就可能据此调整下一拍攻击。因此，我们必须增加攻击者信息集的分析，不能仅凭有限互信息就宣称抵御自适应攻击。

## **十、我现在的最终判断**

这次修改比之前单纯研究二维 LC-TCW 更接近一篇完整的分布式状态估计安全论文。

我建议暂时把论文的核心方法确定为：

**多维时序耦合乘性水印（Angular-Coupled Multiplicative Watermarking）。**

但我不建议现在就冻结具体参数，也不建议立即重写全文。

还有一个特别值得研究的问题：

> 当测量维数 \\(m\\) 增大时，角度耦合带来的检测收益为什么可能下降？是否存在一个与测量维数、奇偶窗口长度和攻击方向相关的最优耦合强度？

这可能进一步形成一个有价值的维数依赖理论，而不仅仅是多跑几组仿真。

**我的下一步会优先把 ACMW 接入原论文的50节点实验，先验证原系统下的真实检测率和估计 RMSE。** 只有这一步通过，我们才把它正式确立为第一篇论文的替代水印机制。
