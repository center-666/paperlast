# 十拍 A0 的严格报警前风险

基线为 [paperlast 冻结提交 74819cd7](https://github.com/center-666/paperlast/commit/74819cd7963417612e384be7974074c2380cdc13)。以零为下标，固定记录中的普通十拍 A0 于第 7 拍起始。量化界与积分聚焦第 7–9 拍，防御器保留未知起点模型及原 BF=20 报警规则。

## 结果与决定

**满足继续条件 A。** 对两个冻结模型的标准常半径状态创新饱和，严格报警前风险为零当且仅当半径不超过 $\sqrt{0.1}/2$。零风险的最低 32 拍名义健康 MSE 成本，相对 V0 约为 **+7.0705%**（不稳定模型）及 **+6.8651%**（稳定模型）。在至多 +2% 健康成本下，首包风险经有理证书分别至少为 $1.24484\times10^{-6}$、$3.30578\times10^{-6}$。这些是保守概率下界，点估计另见数值表。

|常半径饱和条件|不稳定模型首包严格风险下界|稳定模型首包严格风险下界|
|---|---:|---:|
|健康 MSE 不超过 $1.02 J_{\rm V0}$|0.00000124484|0.00000330578|
|半径至少 0.34，含冻结名义匹配点|0.00053137828|0.00154301882|

继续研究的命题限于**固定模板、原 BF 与标准常半径饱和的健康成本—严格时序风险边界**。条件 B 尚未达到。名义匹配点的数值积分支持饱和在两个模型上的低风险方向，精确等成本和可推广的 V1a 排序仍缺证据。

## 复算

在完整冻结研究树下运行，或通过 `--baseline` 指定含基线目录的研究树。复算需要 Python 3.10 和 [已核对的依赖版本](requirements.txt)。

```text
python -B -m unittest -v
python -B run_joint_analysis.py
```

复算脚本核对 36 项冻结输入的摘要，对每模型 12 条已有完整输入逐项对照原接收器。积分采用四个预定 Sobol 扰码，每次 512/1024 个嵌套积分节点，节点用于求积。输出见 [逐项数据](results/results.json) 与 [单元测试日志](results/test_log.txt)。
