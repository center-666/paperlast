**结论：** 固定观察条件下，名义后验迹与固定 A0 的修正误差均方是不同的目标。取原 12 个水印前缀平均，对健康噪声积分后，首包条件误差仍约为工作迹的 7.36 / 4.82 倍。显著差距主要经活动/起点混合形成。已知真实起点的方向失配虽可精确写出，但不是首包差值的主要来源。各项不是独立贡献，需要保留交叉项。继续保留 V1a 为精度基线，暂不启动组 D。

复算：在冻结基线把本目录与原离线验证、原接收器及归档目录放在同一父目录。从本目录运行，需 Python 3.10+、NumPy、SciPy。

```sh
python -B audit_early_calibration.py
```

命令只从已有 NPZ 读取保存的合成传感器轨迹、解码器及 A0 差值；检查 36 个依赖文件的哈希，原样调用接收侧后验核对，再运行解析已知起点风险和条件 Gaussian 求积。只在当前目录写入 `early_calibration_results.json`；也可用 `--out` 指定输出位置。`--quick` 是精度较低的程序检查。没有新攻击、量测、水印试验或接收器。
