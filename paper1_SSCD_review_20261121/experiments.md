# SSCD 原型执行与验证结果

本轮固定 [登记](registration.json)中的预算和种子；所有新结果写入本目录。未合并来源分支，未改动旧结果、冻结增益或原稿。源码原型来自 `548a031`，保留在 [source_snapshot](source_snapshot)。

## 1. 两个阻断问题的复现与修正

- 原代码对 $\zeta=\pm.99999$ 的反解均报 `ValueError`，默认优化同样在首批端点报错。修正版先建立互信息预算区间，并限制在验证过的 $\theta\in[-20,20]$；本轮低预算下域限制没有激活。默认有限模板搜索已成功执行。
- 源 README 的有符号 Gibbs 恒等式符号反向。取 $\Gamma=\Gamma_\theta,\theta=1$ 时，实际 MI 正，而原式右端等于其负值。修正推导见 [review.md](review.md)，没有篡改来源快照。
- 对 $m=2,3,4,6,10$、$\theta=-20,-5,-1,0,1,5,20$，检查 128/256/512 阶 Beta 加权求积与逆映射。最大跨阶差小于 $10^{-8}$；二维另与缩放 Bessel 函数的精确关系交叉核对。该数值稳定性不是形式误差证书。

## 2. 有约束的连续二维参数设计

每个攻击集合是原预定自主轨迹在真实编码能量 10 下的完整有效二维参数球面。五个模型都使用本身的能量 Gram，不只测试普通方向。检测窗口对原自主轨迹是内部奇偶隐蔽窗；优化未知边界或整段 BF 不在此结果中。

每步统计依赖预算 .1 nats，状态最坏污染预算设为 iid；还要求数值上 $Q(\zeta)-Q(0)$ 在完整注册参数空间内非正。内层 256 点角度网格附带解析连续误差界；外层区间搜索目标 gap 设为 $5\times10^{-4}$，上限 1,500 次评估。

| 系统 | 选定 $\zeta$ | 选定 $\theta$ | iid 最坏 $D_G$ 上界 | 候选连续最坏 $D_G$ 括界 | 最终策略 gap 上界 |
|---|---:|---:|---:|---:|---:|
| 同向扩张 | -0.312227 | -1.315237 | 0.464835 | [0.537973, 0.538044] | 0.000294 |
| 扩张加旋转 | +0.312227 | +1.315237 | 0.464835 | [0.537973, 0.538044] | 0.000294 |
| 冻结不稳定补充模型 | -0.312227 | -1.315237 | 0.083207 | [0.098367, 0.098406] | 0.000497 |
| 冻结稳定补充模型 | -0.312227 | -1.315237 | 0.378079 | [0.441442, 0.441532] | 0.000493 |
| 区域补充模型 | -0.312227 | -1.315237 | 0.193152 | [0.211455, 0.211535] | 0.000480 |

这五个例子均在依赖预算边界选择参数，不意味着一般系统的最优值都在边界。使用正/负号是重要部分：旋转例子中沿用固定负记忆会有害，SSCD 改为正记忆。把同向与旋转几何合成一个冲突检测集合时，代码保留 iid，剩余目标 gap 约 0.000307。它是鲁棒目标退路测试，不是另一个原网络实例。

所列括界与 gap 为浮点评估的解析离散/区间界，不是向外舍入证书；也不是实际 KL 或功效的界。二维连续攻击范围只指有效参数 $p=2$。通用有限模板 API 可以使用更高测量维数，但没有因此解决任意 $p$ 的连续最坏攻击。

## 3. 原共 G 污染风险约束

下表是整个指定输出时域的**最坏攻击附加 MSE**，不是总状态 MSE，也不是检测后补偿器风险。

| 系统 | iid | 选定耦合 |
|---|---:|---:|
| 同向扩张（两拍教学系统） | 0.780289 | 0.767615 |
| 扩张加旋转（两拍教学系统） | 0.780289 | 0.767615 |
| 不稳定补充模型（32 拍） | 0.0450391 | 0.0447270 |
| 稳定补充模型（32 拍） | 0.0426256 | 0.0423951 |
| 区域补充模型（32 拍） | 0.3875822 | 0.3839727 |

三个补充模型保持原共 G、十拍编码能量和固定起点 7。原攻击参数空间中的逐方向变化最大值也均为负。对选定参数不再调节，额外检查每个有效起点 $\tau=0,\ldots,22$；这 23 个起点中各模型的能量归一化风险差仍数值非正。起点敏感性是固定策略的独立矩核查，不是已经解决未知起点的在线识别或检测延迟。

理想健康编解码下，原共 G 健康输出本来就逐路径不变，所以这里没有用额外健康收缩器来换取这些结果。若未来检测触发隔离或恢复，必须重新验证该最终输出。

另将固定策略按攻击段 7–16、停止后 17–31 与每个逐时输出分别收缩状态风险矩。三个补充模型攻击段最坏期望污染由 iid 的 0.143773/0.136393/0.926247 变为选定水印的 0.142777/0.135655/0.917311；停止后分别由 0.00025141/$2.51385\times10^{-5}$/0.209796 变为 0.00024976/$2.49437\times10^{-5}$/0.208053。23 个有效起点和 32 个输出时点的能量归一化参数最坏风险差均数值非正。这里是期望均方矩，不是样本路径峰值、首次危险事件或报警后估计误差。

## 4. 独立健康校准与真实单窗功效

每个模型只用独立的 100,000 个名义白化残差确定同一个 95% 分位阈值，然后所有水印共用该阈值。没有逐方案调阈值追求所需 TPR。用 20 批、每批 5,000 条新噪声/水印轨迹，评价在训练模型冻结的最坏代理方向上的单次检出率。

| 系统 | iid | SSCD 选定耦合 | 配对变化（百分点） | 变化批 SE（百分点） |
|---|---:|---:|---:|---:|
| 同向扩张 | 22.183% | 23.932% | +1.749 | 0.180 |
| 扩张加旋转 | 22.150% | 23.961% | +1.811 | 0.191 |
| 不稳定补充模型 | 11.776% | 12.302% | +0.526 | 0.111 |
| 稳定补充模型 | 21.339% | 22.136% | +0.797 | 0.161 |
| 区域补充模型 | 16.674% | 16.961% | +0.287 | 0.163 |

区域模型的差值不足两个批 SE，不能宣称已建立可靠功效优势。固定正耦合和固定负耦合的完整对照均保存在 [results.json](results.json)，其中旋转例子的负耦合实际功效下降，与上轮反例一致。

这些是单个内部窗口的实际非 Gaussian 功效数据。它们不等于整段 BF、检测延迟、报警前风险或连续攻击集合的最坏真实 TPR。

## 5. 额外留出方向轮廓

冻结 SSCD 后，取 32 个相对内层网格错开的角度，每个方向 3,000 条新水印/噪声样本，只比较 iid 与选定策略，结果见 [heldout_results.json](heldout_results.json)。未用此组结果回头选符号或调阈值。

独立复核发现，初次写为 $(j+.5)\pi/32$ 的角度恰好是原 256 网格上的 $(8j+4)\pi/256$，不能称为离网格方向。初版保存在 [heldout_initial_on_grid_results.json](heldout_initial_on_grid_results.json)。正式轮廓改为 $(8j+.5)\pi/256$，恰在原网格相邻点中间；仅修正评分方向，策略、阈值和随机种子全部保持冻结，不据此重新优化。

| 系统 | iid 的 32 方向经验最小 TPR | SSCD 的经验最小 TPR |
|---|---:|---:|
| 同向扩张 | 21.767% | 22.933% |
| 扩张加旋转 | 21.067% | 22.700% |
| 不稳定补充模型 | 11.200% | 12.167% |
| 稳定补充模型 | 19.933% | 20.800% |
| 区域补充模型 | 17.133% | 16.900% |

这些经验最小值带有取最小的抽样偏差，没有给出连续方向的功效证书。区域模型的经验最小值略降，其差别也不能证明真实最坏功效显著下降；它不支持稳健检出改善，应保留为当前证据边界，不能只展示平均值上升。

## 6. 代码与复算

依赖 Python 3.11、NumPy 2.4.6、SciPy 1.17.1；源码 [sscd.py](sscd.py)可独立调用有限模板接口。连续二维求解另需 [continuous_design.py](continuous_design.py)。实验脚本读取同仓库上一轮已冻结补充模型，不会创建假的 50 节点配置。

```text
python -B test_sscd.py
python -B run_checks.py
python -B heldout_scope.py
```

六项回归测试覆盖紧致域、iid、PSD/能量拒绝、一般测量维数有限接口、$m=3,p=2$ 连续接口、拒绝将 $p=3$ 伪作圆周，以及带符号采样的边缘和方向记忆。风险多项式还与来源代码的独立矩阵实现交叉核验。
