# **二、理论部分：有四个结论需要正式保留**

## **2.1 跨拍协方差公式是成立的**

你本轮把原来的两个参数进一步压缩为：

\\[ \boxed{\zeta=\rho\frac{mc\_\kappa-1}{m-1}} \\]

其中：

\\[ c\_\kappa=-\frac{\partial}{\partial\kappa}\log Z_m(\kappa) \\]

于是：

\\[ E[(u_k^\top u\_{k+h})^2] =\frac1m+\left(1-\frac1m\right)\zeta^h \\]

这个简化是成立的。

我还重新核对了交叉协方差中的转置方向：

\\[ \boxed{ C\_{\ell r} = \frac{q^2m}{m+2}\zeta^h \left[ (d\_\ell^\top d_r)I+ d_rd\_\ell^\top- \frac2m d\_\ell d_r^\top \right] } \\]

其中 \\(q=\sigma\_\beta^2\\)。

需要注意两个细节：

- 偶数滞后的相关系数为正，不能只研究相邻方向。
- \\(\zeta\\) 只在指定旋转不变、符号偶对称的 Markov 核族内，才能完整代表这里使用的四阶矩结构。

因此，这个标量化是有价值的理论贡献候选。

## **2.2 最大熵命题值得保留，但应当升级**

我认为这是本轮最漂亮的数学结果之一。

在给定：

\\[ E[(u_k^\top u\_{k+1})^2]=c \\]

的条件下，指数倾斜核：

\\[ g\_\theta(v|u) = \frac{\exp(\theta(u^\top v)^2)}{Z_m(\theta)} \\]

最小化相邻方向的互信息。

证明可以直接使用相对熵非负性：

\\[ D(\Gamma\\|\Gamma\_\theta)\geq0 \\]

因此，同一个方向二阶记忆可以由统计依赖更小的水印实现。

不过我建议再推进一步。

原来只研究：

\\[ \theta=-\kappa\leq0 \\]

这只允许方向排斥。

现在应当允许：

\\[ \boxed{\theta\in\mathbb R} \\]

这样就同时包含：

- \\(\theta<0\\)：方向排斥；
- \\(\theta=0\\)：独立 Gaussian；
- \\(\theta>0\\)：方向对齐。

重要算法升级

这一步非常关键。

既然旋转系统中负耦合会降低检测性能，我们就不能把算法限制在负耦合区域。

**下一版算法应该优化有符号的&#x20;**\\(\zeta\\)**，而不是只寻找最强的方向排斥。**

## **2.3 原共 G 风险桥接成立，但不能夸大收益**

你给出的：

\\[ \Delta J=\xi^\top Q\_\Gamma\xi \\]

非常值得保留。

我核对了它的三个部分：

1. 水印均值造成的累计污染；
2. 单拍水印协方差产生的污染；
3. 跨拍相关产生的交叉污染。

这三项能够统一写进 \\(Q\_\Gamma\\)。

尤其是：

\\[ Q\_\Gamma(\zeta) \\]

与奇偶残差协方差使用同一组 \\(\zeta^h\\) 系数。

这就建立了一个很好的理论接口：

**水印时序参数&#x20;**\\(\zeta\\)

**奇偶残差协方差**

\\(C_r(\zeta)\\)

检测性能

**共 G 风险矩阵**

\\(Q\_\Gamma(\zeta)\\)

状态估计安全性

**系统相关的联合水印设计**

但有一个重要限制：你目前的状态风险是预定攻击、固定共 G、外生水印条件下的风险。

它还不是检测后隔离、恢复之后的最终风险。

所以第一篇论文现阶段应当先研究水印如何改善检测与原共 G 的攻击响应，不要过早把主动恢复写成已经实现的贡献。

## **2.4 原攻击能量定理必须补足条件**

这一点我认为审稿人很可能追问。

不能只要求整体奇偶矩阵满行秩，还需要：

\\[ c_Z= \min\_\ell \operatorname{tr} (\Theta^{-1}Z\_\ell Z\_\ell^\top)>0 \\]

也就是每个时间块都必须对奇偶残差具有有效作用。

另外必须明确：

- 攻击与整窗水印独立；
- 名义残差为 Gaussian；
- 攻击残差均值为零；
- 相关矩阵满足相应正定条件。

否则不能直接把原来的攻击能量抑制定理照搬过来。

# **三、我认为下一步应该开发什么算法？**

这里是我最想推进的部分。

我建议正式采用：

**SSCD：System-aware Signed Coupling Design，系统感知有符号耦合设计。**

它不是再提出一种新的估计器，而是利用原有水印结构，根据系统几何自动选择耦合程度和方向。

## **3.1 联合优化问题**

令攻击参数为 \\(\xi\\)，编码域攻击能量为：

\\[ \xi^\top E\xi=E_0 \\]

我们考虑：

\\[ \boxed{ \begin{aligned} \max\_{\zeta}\quad& \min\_{\xi\in\mathcal X_E} D_G(\zeta,\xi)\\\ \mathrm{s.t.}\quad& (L-1)I_m(\theta(\zeta))\leq B_I,\\\ &E_0\lambda\_{\max} \left(E^{-1/2}Q\_\Gamma(\zeta)E^{-1/2}\right) \leq B_J,\\\ &-\frac1{m-1}<\zeta<1. \end{aligned} } \\]

这里：

| 变量/约束           | 意义           |
| --------------- | ------------ |
| \\(\zeta\\)     | 有符号水印时序记忆    |
| \\(D_G\\)       | 检测性能代理       |
| \\(I_m\\)       | 水印时间统计依赖     |
| \\(Q\_\Gamma\\) | 原共 G 的攻击污染风险 |
| \\(B_I\\)       | 预先指定的依赖预算    |
| \\(B_J\\)       | 原共 G 的状态风险预算 |

这里的状态风险预算建议设为：

\\[ B_J=J\_{\mathrm{iid}}^{\mathrm{worst}}+\epsilon_J \\]

也就是以 iid 水印最坏攻击风险为基准，允许预先规定的变化量。

注意，不能直接把能量球包含零攻击时的最坏检测目标写成上述形式，否则最坏检测指标恒为零。必须使用固定正能量集合或预登记的非零攻击族。

## **3.2 算法流程**

## **SSCD 算法架构**

1. **读取原始系统**

   提取 \\(A,H_i,Q,R_i\\)、通信拓扑、原共 G 增益和奇偶矩阵。
2. **构造攻击集合**

   使用原有严格隐蔽 FDI 结构，按真实编码域能量归一化。
3. **解析预计算**

   计算各时滞的跨拍协方差系数，以及共 G 风险矩阵系数。
4. **建立一维参数映射**

   根据 \\(\zeta\\) 反求 \\(\theta\\)，计算互信息。
5. **系统感知优化**

   在检测代理、时间依赖预算和状态风险约束下寻找候选参数。
6. **独立验证**

   用真实水印轨迹计算检测率、误报率、检测延迟和最终状态 MSE。

最重要的是：iid 水印必须始终作为可行基线。如果某个系统下所有非零耦合都无法改善检测且满足状态风险约束，就退回 iid，而不是强行使用 ACMW。
