# 水印条件增益封顶：定理级独立性门槛

日期：2026-11-14。候选为`ρ(M)=min(1,γ/||GM||₂)`，只改变目标邻居解码新息进入原共同增益G的系数。本文限定为文献与数学接口筛选，不先认定创新成立；不转向MAC、调度、恢复或强化学习。

## 1. 候选实际增加了什么？

原方案以G接收精确解码后的量测，新候选以ρ(M)G接收同一创新。乘性水印仍负责改变攻击到奇偶残差的映射；ρ负责限制当前实现下的攻击通道诱导增益。

在当前M合法可得、固定G和ρ不读攻击标签/量测的条件下，

\[
\|\rho(M)GMa\|\le\gamma\|a\|.
\]

这是一条标准诱导范数封顶不等式。它是可检验能力，不等于完整估计偏差上界，更不是未知起点危险前报警保证。新的状态转移也含ρ，不能只把旧攻击输入矩阵改小而保持旧F或正常协方差。

从结构看，这不是“检测后才降权”：ρ可以在统计报警之前计算。但“未报警时也限制数据影响”已有鲁棒融合先例，不能把时间顺序不同当作原创。

## 3. 不能把候选与普通饱和直接当成同一个算子

普通创新饱和/裁剪可令`u=clip_τ(Gν)`，其更新量满足`||u||≤τ`，是载荷相关非线性。候选则`u=ρ(M)Gν`，即使ρ>0固定，Gaussian健康创新仍无界；它限制的是`a↦ρGMa`的算子增益。两者的保证对象、正常损失和偏差差分项不同。

因此，若数学审查只写“ρ属于饱和所以完全等于He算法”，并不准确；但若反过来写“ρ依赖秘密所以超越饱和”，同样没有证据。应比较同η下的实际危险风险及编码成本，保留正常递推和联合概率。

## 4. 与归一化Gaussian的区别也必须说准确

把解码乘子改为`\bar M=cM`，同时把编码器改为`(cM)^{-1}`，无攻击时仍恢复原量测y，原G融合保持不变；但正常编码信号能量按c^{-2}改变。候选保留原编解码，只在融合端乘ρ，所以健康创新也按ρ缩小，正常估计递推改变。

即便在某个攻击输入上`ρGM=G\bar M`，也不能由此宣称两种完整估计器相同；名义项和信号成本并不相同。归一化Gaussian是必要资源基线，不能只按期望残差响应匹配后便宣布安全性等价。

单标量情形下，若`M≥λ>0`且γ≤|G|λ，候选始终处于缩放段，`ρ=γ/(|G|M)`，所以`ρGM=γ sign(G)`与M无关。该边界说明“ρ使用秘密”不意味着估计通道中一定保留不可替代的秘密增益；这种情况下应特别审查是否只是为恢复一个固定有效输入增益而付出了随机名义降权损失。本轮m=2一般不直接化为此标量等式。

## 5. 可以成为新增结果的最低证据，而不是预定结论

要从“水印加接收端降权”提升为独立耦合方法，至少应有：

1. 在固定M分布、实际编码资源及原聚合结构下，正常MSE约束明确，接收端ρ可因果执行。
2. 在同一预定模型一致性FDI及同一E/D和事件误报下，比最佳固定ρ、单独裁剪、无水印和符号基线取得严格或有力认证的风险—正常精度分离。
3. 检测器保留未乘ρ数据；任何检出率差别须区分ρ本身与攻击者重新响应。多拍传播、停止尾部和首次报警事件不靠平均非中心性替代。
4. 对比He等载荷饱和和Gallo等损害设计时，指出实际不同且已证明有用的性质，不能仅用变量依赖项或新损失函数名称作为差异。
