# JFI修订研究决定：C，停止当前水印感知ρ候选

日期：2026-11-14。本轮沿原稿乘性水印主线，未改为MAC、调度、恢复或强化学习。原架构仍为邻居原量测先求和、共用G；只在用户授权的目标邻居融合处加入ρ。模型是上轮明确补充的相容五节点实例，不是原50节点最终配置复现。

## 1. 最终验收回答

**本轮没有证明当前秘密水印信息带来了优于单独水印、单独鲁棒融合及简单组合的、同资源和正常精度下的独立耦合收益。当前候选创新性不通过，不值得写入正式论文作为新方法。**

可以成立的数学是：`||ρGM||≤γ`；水印独立物理噪声时的正常误差/协方差递推；攻击偏移的随机转移；全时域能量增益界。这些属于标准算子缩放、随机二阶矩与稳定性工具。依赖当前秘密并不自动使上述推论成为原创。

停止的是`ρ=min(1,γ/||GM||)`这个具体候选，不是否定所有乘性水印接收端研究，也不把表现更好的普通裁剪重新包装成本论文新贡献。

## 2. 为什么没有通过，而不是只因尚未完成大实验？

1. **检测没有被ρ增强。** 同一攻击a和同一M下，未经ρ改写的解码奇偶残差完全相同，有限时间单次功效不变。ρ只能影响被污染数据进入估计的作用；攻击者重选方向后功效变化是另一件事。
2. **正常精度有真实代价。** 随机ρ的稳态协方差不优于固定其均值ρ的协方差，已有严格PSD差方程。1%、5%、10%、20%预算中，前几个预算没有稳定优于同编码固定ρ；20%只有约1—2个百分点的首包候选风险改善，尚非全局最坏值。
3. **简单Gaussian＋普通裁剪是更强反证。** 固定阈值裁剪使用同一个Gaussian编码、同一未加权检测器和相同预算口径。η20的新鲜样本核对中，裁剪连续首包能量球风险上界约.520/.487，而候选某固定合法首包攻击的风险下界约.660/.629；该抽样结论有明确模型/初始化/置信前提。裁剪正常MSE验证约19.9%，尚无严格≤20%证书，因此不把它宣称为完整理论支配定理；但它已提供有力的最小强基线否定证据。
4. **可证零风险点付出过高正常损失。** 保守γ=.09时有任意有限总能量10攻击全时域偏移平方≤405/4118<.1，包括停止尾部；然而正常MSE诊断损失约72%/66%，超出事前最大20%。固定符号＋固定衰减也有同类保证，而且此点正常损失约42%/39%。安全界没有显示新水印耦合能力。
5. **期望损害改善不等于验收风险改善。** L10的P1/P3已重算，保留Fρ与ρGM同拍相关性。P1期望终端损害确会下降，部分P3-phys集合变空；这些不能解释成100%检出，也不能替代危险先报警的事件目标。

上述负判断没有改变E=10、D=.1、原Gaussian分布或五节点估计器来追求结果。普通裁剪是追加的必需基线，不是新候选开发。

## 4. 最后定位

该ρ规则是利用水印实现对融合通道作标准范数封顶，与创新裁剪、归一化编码并非整个算法完全相同；本轮没有伪造这种等价。真正的否定理由是：**不同之处尚未带来强基线无法替代的性能，最小筛选反而支持更简单的已有组合。** 因此A不成立，也不以B无限延长同一候选的调参研究，选择C停止。
