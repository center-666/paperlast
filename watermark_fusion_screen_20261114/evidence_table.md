# 证据等级与边界

|结果|等级|范围|
|---|---|---|
|rho GM即时范数≤γ|严格代数|直接项，不等于累计偏差或总估计误差|
|水印独立rho的正常协方差/随机权重代价|严格二阶矩恒等式与Lyapunov比较|固定K/G、M独立物理，不适用于载荷裁剪系数|
|Fρ/ρGM同拍相关的P1/P3|正确矩递推＋浮点求积|L10期望终端偏移，不是危险风险|
|c=.42与γ=.09全时域界|有理矩阵核查＋上一轮DARE误差桥|原相容五节点目标、零进入影子偏移、无报警门控比较|
|γ=.09的66—72%正常代价|浮点二阶矩求积|超事前η预算，非工程规格|
|同a/M时rho不改Pd|严格条件分布恒等式|检测使用未乘rho的解码数据|
|η预算参数与正常P|浮点确定性求积/矩方程|有升级及残差检查，非实数区间证书|
|首包风险优化表|浮点积分与有限方向/局部搜索|有窄角积分误差，使用分段复核值；非全局最坏|
|普通裁剪正常MSE|独立噪声路径验证与配对SE|均值约19.9%但不严格认证≤20%|
|首包覆盖网格风险上/下界|Lipschitz事件包含＋有限样本浓缩|独立新种子、理想IID抽样、冻结数值模型/有限预热初始化；非完整攻击族风险|
|归一化Gaussian成本/P1/P3变换|矩恒等式＋浮点积分|只任务B诊断，未改变任务D随机分布|
|审稿意见及近邻|原附件/原公式及既有指定页核对|未宣称动态水印全算法复现或近年缺全文论文排重通过|
|创新性|本轮不通过|C停止具体rho候选，不是所有接收端水印机制不可能有效的定理|
