## **一、二维 Watson 水印可以精确转化为 von Mises 方向采样**

原有水印形式保持不变：

\\[ M_k=0.5I+\beta_k\beta_k^\top,\qquad \beta_k=r_ku_k. \\]

设二维单位方向 \\(u_k=(\cos\alpha_k,\sin\alpha_k)^\top\\)，原 SSCD 的转移核为：

\\[ p(u\_{k+1}\mid u_k)\propto \exp\left[\theta(u_k^\top u\_{k+1})^2\right]. \\]

利用恒等式

\\[ \cos^2\Delta\alpha =\frac{1+\cos(2\Delta\alpha)}2, \\]

令 \\(\phi_k=2(\alpha\_{k+1}-\alpha_k)\bmod2\pi\\)，得到：

\\[ \boxed{ p\_\theta(\phi) = \frac{\exp[(\theta/2)\cos\phi]} {2\pi I_0(\theta/2)} } \\]

其中 \\(I_0\\) 是第一类修正 Bessel 函数。

这意味着可以用同一个均匀随机变量 \\(U_k\\) 和不同的 \\(\theta\\)，通过分布函数逆变换生成不同水印候选。配合独立的二值方向分支，生成结果与原有有符号 Watson 转移核同分布。

同时获得两个简洁解析式：

\\[ \boxed{ \zeta(\theta)=\frac{I_1(\theta/2)}{I_0(\theta/2)} } \\]

\\[ \boxed{ I_2(\theta)= \frac{\theta}{2}\zeta(\theta) -\log I_0(\theta/2) } \\]

因此二维情况下，时间相关性和相邻互信息可以直接计算，不再依赖一般超几何函数的数值求解。

### **实际价值：降低选参方差**

此前不同候选的转移方向使用独立随机流，尽管物理噪声相同，配对 MSE 差值仍包含大量无关的水印采样波动。

现在可以让 iid 和负耦合共享相同的径向变量、初始方向、逆分布采样随机数和方向分支。**这只改变离线实验的随机数耦合，不改变任何候选水印的边缘分布或在线安全协议。**

\\[ Z=(u_k^\top u\_{k+1})^2. \\]

在独立均匀方向下：

\\[ Z\sim\operatorname{Beta}\left(\frac12,\frac{m-1}{2}\right). \\]

有符号 Watson 核恰好把该 Beta 分布进行指数倾斜：

\\[ \boxed{ f\_\theta(z)= \frac{e^{\theta z}f_0(z)} {{}\_1F_1(1/2;m/2;\theta)} } \\]
