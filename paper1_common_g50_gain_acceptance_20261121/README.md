## 独立重算与附件的关系

没有拿到附件所用计算程序或其实际增益数组，本目录依据附件公式独立重算。

| 指标 | 不稳定 A | 稳定 A |
|---|---:|---:|
| 全部注册模式最大谱半径 | 0.0965019734 | 0.0904282373 |
| 全部注册模式最大二范数 | 0.0968185375 | 0.0904288582 |
| 最大点所在节点 | 35 | 35 |
| 与独立 SciPy DARE 预测协方差之差（Frobenius） | 3.52×10^-15 | 5.70×10^-15 |
| 本实现最大固定点迭代次数 | 8 | 8 |

主要增益和稳定性数值与附件相符。附件的“7 次”不是本实现复现出的次数：本实现从 5I 开始，用后验差 Frobenius≤10^-14 停止，最多 8 次；附件未给原代码和停止判据，不能宣称逐项复现其迭代日志。完整残差定义与值在 [gain_table.json](gain_table.json)。

“57”必须称为节点局部配置数；全网组合为 64。这里交换原始量测，各接收者仅用自己的预测，因此全网齐次矩阵为局部 F 的块对角阵，局部统一范数界足以覆盖这些联合模式的任意切换。

## 理论上新推进了什么

[THEORY.md](THEORY.md)给出可审查证明：

1. **任意保留集合的收缩与 DARE 唯一性。** 本地量测不删、H 对角元在 [1,1.5)、Q=I、R=.5I 时，名义信息矩阵满足 `2(1+d)I ≤ J ≤ 4.5(1+d)I`。从而 `||F||₂ ≤ .5||A||₂ < 1`，对应后验 Riccati 映射全局压缩，固定点唯一。该理论族允许任意正确重算的集合；当前软件查表只覆盖已登记六边的模式。
2. **交付系数的更强保证。** 不依赖它们恰为精确 DARE 解，直接用交付十进制 K/G/H/A 构造 F，逐项以有理数认证 `.01I−FᵀF ≻ 0`；解析后的 IEEE 系数也另行通过。这认证精确系数模型，不包办运行时每次浮点舍入。
3. **攻击停止后的恢复界。** 原始报文检测缓冲不删样本、不锁存时，[50,110) 攻击从 k=117 起已完全离开全部分数缓冲。新查表协议的增益立即相同，理想模型中 `||b_(117+h)|| ≤ .1^(h+1)||b_116||`。这是配对污染回到健康基线，不是绝对 MSE→0，也不是某种水印独有收益。
4. **聚合损失可量化。** 在本噪声配置下，`J_stacked−J_aggregate = 2Σ(H_j−H_mean)ᵀ(H_j−H_mean) ≥ 0`，明确共 G 的原始量测压缩与旧自由堆叠 KF 的关系。
5. **下一阶段健康校准的严格秩规则。** 另提供 [calibration_rule.py](calibration_rule.py)。512 条健康路径的全决策最大分数用第 488 个顺序统计量、严格 `>` 告警，可给 `25/513≈4.8733%` 的边际路径 FWER 上界。它不是给定某个固定校准集后的条件保证；当前兼容 runner 仍用 raw42，没有静默替换。

## 两个必须带入下一阶段的审稿意见

**原阈值 42 仍有启动必报警。** k=5 仅两个八维残差样本，样本协方差秩亏使正则化 plugin 分数已有大于 42 的确定下界。兼容验收保留并暴露它；不能把通过兼容测试当成完成健康校准，或把它叫卡方检测。

**已知六候选边的静态丢弃仍是强基线。** 无需新 MC，按固定增益真实健康协方差递推计算：始终删去这六边的全网健康成本约为 +1.0703%（不稳定）/+1.0699%（稳定）；五个受影响接收节点成本约为 +13.047%/+13.039%。若允许全网 2% 健康成本，它可拒绝全部登记攻击；严格零损失或未知攻击支持下则需另议。[nominal_theory_checks.json](nominal_theory_checks.json)完整记录，不能只报全网稀释后的成本。

数据相关门控时，模式 DARE P 只是增益设计量，不等于真实条件误差协方差；模式增益也不能自动称为选择后的 MMSE。稳定性来自本地健康观测，攻击期间的安全性能取决于攻击输入、时序水印和门控全过程。
