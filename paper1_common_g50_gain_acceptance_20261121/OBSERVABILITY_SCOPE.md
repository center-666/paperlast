# 50 节点实验的可观测性范围审计

用户指出当前 50 节点估计器的研究动机是处理局部部分不可观测，但所用攻击边似乎传输了完整二维量测。核对冻结输入和更新代码后，这一判断成立。

## 冻结配置事实

- 状态维数为2，单节点量测维数也为2。
- 所有50个节点的 `H_i` 都是对角 `2x2` 矩阵；实际对角元范围为 `[1.00276106, 1.49344348]`。
- 50个 `H_i` 的秩全部为2；最小行列式约 `1.06734`，最大二范数条件数约 `1.46983`。
- 每条 `(receiver,sender)` 报文传输一个 `y_j,k` 二维向量；六条登记攻击边也向该二维报文注入二维攻击偏移。

因此每个节点的单拍无噪声映射 `y_i=H_i x` 已经可逆。实际滤波仍有意义，因为有过程噪声和量测噪声，邻居信息可以降低噪声并提供冗余；但当前仿真不是“节点各自缺少必要状态模态、必须靠网络互补观测才可估计”的配置。

## 对现有结论的影响

新共 `G` 误差收缩证明显式依赖每个接收节点始终保留本地满秩 `H_i`。它也说明为什么本配置在隔离邻居后仍非常稳定。该收缩保证不是部分可观测网络下的证据。

目前关于六边攻击、负耦合水印、门控后 MSE 和已知六边静态删除 oracle 的数值结论仍对**此冻结的满秩、强本地观测噪声融合系统**有效。它们不能回答“时间耦合水印能否让依赖分布式邻居信息的部分可观测估计器更安全”。静态删边基线表现强，也与本地传感器独立恢复两个状态分量的结构相容。

这不推翻该系统上的水印统计或门控机制结论，但收窄论文应用主张：目前展示的是满秩 noisy local sensors 上的安全融合效果，尚不是部分可观测系统的网络协同收益。

## 若论文目标确实是局部部分不可观测

下一套物理配置需要先满足以下定义，再讨论性能：

1. 每个节点的 `H_i` 对目标状态至少有一个不可观测方向（例如秩小于状态维数），而整个网络在声明的通信/门控模式下有共同的可检测性或可观测性。
2. 明确估计目标、状态动力学模式、节点局部观测子空间及其网络互补关系；报告每个单节点和全网/局部邻域观测矩阵的秩与可检测性证据。
3. 对新 `H_i` 重算基准及门控模式的共 `G` DARE，重新验证增益有界、切换稳定性和模式缓存覆盖。现有 `c=.1` 有理证书绑定旧 `H_i`，不可沿用。
4. 验收在关键局部观测方向被邻居门控后是否仍可检测。若某些模式下丢失不可观测模态，就应分析可用邻居条件、驻留时间或观测联合，而不能继续假定任意模式每拍收缩。
5. 水印检测也须跟测量维数相容。若改成每个节点只传一个标量量测，当前二维 Watson 方向耦合和 `m=2` 互信息预算不再是同一个机制，必须重新定义与证明。
6. 将健康融合、攻击门控、共 `G` 更新和静态删边基线都在该新配置下重新运行；当前满秩 50 节点结果作为独立场景保留。

必须保留新配置的 `H`、邻接图、攻击边、源哈希和分析登记，确保部分可观测是模型的真实性质，而不是事后用文字描述出来。

## 源证据

`physical_configuration.json` 是 `049bdc6` 冻结快照的逐字节副本，其 `H` 采用 node-major `[50,2,2]`。`run_common_g_50.py` 对本地二维创新 `y_i-H_i p_i` 和邻居二维量测聚合求更新。`THEORY.md` 的收缩命题明确建立在 `H_i` 对角元位于 `[1,1.5)`、所以本地信息矩阵有严格正定下界的假设上。
