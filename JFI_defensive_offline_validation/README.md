# 离线防御验证与 A0 在线辨识

基线 [0beb3ed](https://github.com/center-666/paperlast/commit/0beb3edace40d514d1969cde205eba3f3b2272be)。两个五节点模型使用原共 G 更新、原始接收量测上的 BF 和冻结防御参数。接收器通过同一组可信量测、目标量测和解码器前缀独立递推。评估器用物理真值计算 MSE，用同方法的健康估计计算配对偏移。

## 复算

在完整研究树的本目录运行 Python 3.10 或更新版本。

~~~sh
python -m pip install -r requirements.txt
python -B -m unittest discover -v
python -B replay_evaluator.py
~~~

指定另一份完整基线树时，给求值命令传入 --baseline。程序检查 [29 个基线输入的 SHA256](frozen_inputs_sha256.json)，在本目录写入 [汇总结果](results/summary.json) 和 [A0 逐路径辨识数据](results/a0_replay_paths.json)。[测试日志](results/test_log.txt) 记录 11 项通过的测试及两模型重跑输出。

|---|---:|---|

24 条 A0 重跑记录使用归档源样本编号。保留样本的路径编号是原 NPZ 的零基行号。用旧日志交叉核对时，最大绝对差约为 $2.85\times10^{-13}$。接收器输入均来自固定合成记录。

可审阅的新增源码见 [代码补丁](results/code_changes.patch)，复算与冻结检查见 [交付核验](results/verification.json)。

## 事件与配对口径

监测 32 拍，索引为 0–31。危险为同方法的离线配对估计差平方首次达到 0.1，报警为原 BF 首次达到 20。没有观察到事件的路径在 32 处右删失。已危险且窗内无报警进入严格报警前计数。同拍单列。攻击段和停止后的 MSE 都相对保存的物理状态，先对每条路径的对应时间段取平均，再对路径取平均。

配对风险差使用同一物理路径上的两个二值事件。区间由两个不一致单元概率的 Clopper–Pearson 区间作 Bonferroni 合成，在独立同分布路径条件下对单个比较保守覆盖 95%。12 条重跑记录的区间仅作小样本诊断。保留样本区间针对冻结条件下的逐路径差，未进行跨方法或跨场景的同时推断。

## V1a 何时取得足够的辨识证据

对每一帧，接收器只根据其已接收前缀生成所有起点的分量和后验。真起点分量在评分时从这些既有输出中索引。首包的无事件后验均值为 52.0% 和 39.5%，活动后验均值为 9.0% 和 30.9%，真起点后验均值为 1.8% 和 21.5%。非活动后验质量还计入尚未开始或已经结束的起点分量。

令 $\widehat d$ 为 V1a 的总体失真估计，$p_{\rm act}$ 为活动后验质量，$\mu_*$ 为既有后验中真起点分量的均值，$d$ 为归档真值。用 $\widehat d/p_{\rm act}$ 表示仅按活动假设重新归一化的均值。误差分解依次为非活动质量带来的收缩、活动假设的起点混合以及真起点下的拟合误差。结果保留平方展开的交叉项。

|模型和时段|总体失真平方误差|总体估计与真起点分量的平方差|真起点拟合平方误差|两项交叉贡献|
|---|---:|---:|---:|---:|
|不稳定，首包|0.3854|0.1394|0.1648|0.0812|
|不稳定，十拍|0.4680|0.1575|0.2693|0.0412|
|稳定，首包|2.0545|0.8645|0.5339|0.6561|
|稳定，十拍|0.5016|0.2421|0.1655|0.0940|

不稳定模型的十拍误差中，真起点分量的拟合误差平方更大。稳定模型的首包和整段则呈现更大的混合差，其中包括活动概率不足引起的收缩。整体误差受交叉项影响，活动条件下选错起点只解释混合误差的一部分。

当拍共 G 的净补偿残余为 $G(d-\widehat d^a+\widehat d^0)$，对照无补偿的当拍项 $Gd$。有效补偿指平方残余减少超过 $10^{-12}$。两模型各有 12/12 条路径从首包就减小该拍平方残余，残余减半分别只有 0/12 和 4/12。处于攻击段的严格报警前危险中，5/5 和 7/8 条先于活动后验达到 0.5，4/5 和 6/8 条先于首次残余减半。0.5 与减半只用于离线诊断，原 BF 门限为 20。逐拍数值与删失时间见 [A0 逐路径辨识数据](results/a0_replay_paths.json)。

## 可用于论文的结论

A0 的结构信息可用于量化在线估计精度，V1a 在两模型固定起点的保留样本中均有更低的攻击段平均 MSE。标准饱和同时取得更少的严格报警前危险。现有对照支持具体的精度与安全权衡，成熟鲁棒滤波是否能复现 V1a 的精度收益仍缺同约束证据。

已核验的理论主张是**有限时域检测与健康精度的可行边界**。固定 A0 波形在给定水印时产生同协方差的 Gaussian 平移。对危险时间由水印确定的线性接收器，正概率危险在有限误报预算下仍可能严格早于报警。窗口 B 的有理数证书进一步表明，若允许 32 拍任一拍出现满预算单包扰动，当前目标量测仿射类实现零严格报警前危险所需的健康 MSE 增量至少为 2.234% 和 2.257%。十拍 A0 的 2% 可行性仍未判定。[Gaussian 交叠界](../JFI_live_causal_attacker_and_pre_alarm_analysis/01_报警与危险的联合条件.md) · [窗口 B 证书](../JFI_live_causal_attacker_and_pre_alarm_analysis/02_窗口B严格报警前精度证书.md)
