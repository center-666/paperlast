# 共G参考实现的独立代数与索引复核

2026-11-15。仅审查新建`common_g_reference.py`、`test_reference.py`、输入模型及保存的两条32拍轨迹；未改旧文件，未运行历史50节点模块，未生成新物理样本。内部协作审查不是外部同行审证。

**结论：在声明的固定共G、无门控、完整报文、理想同步及既有五节点补充模型内，未发现公式、编码注入位置、时标或名义奇偶协方差错误。参考基线可以通过这一范围的实现接口验收。** 这不认证原50节点历史运行，不支持完整检测—隔离闭环性能，也不改变两项防御候选和分析稿的C决定。

## 1. 公式与时标

`common_step`使用同一预测值`prior=A@previous`计算本地和全部邻居创新，然后执行`prior+K@local+G@sum`。没有先本地更新再计算邻居创新，也没有给每个邻居单独自由增益。

展开原公式得到独立的仿射写法

\[
\hat x_{i,k}=F_i\hat x_{i,k-1}+K_i y_{i,k}
+G_i\sum_{j\in\mathcal N_i}y^d_{ji,k},\qquad
F_i=(I-K_iH_i-G_i\sum_jH_j)A.
\]

本审查没有调用`common_step`、`run_common`、`Model.J`或`bias_recursion`，而按此展开式重算保存的两模型、两编码、健康/受攻全部节点轨迹；与保存数组最大绝对差为约`7.11e-15`。这比单纯重新运行主测试更能排查公共实现路径的自证循环。

预测偏移为\(b_k^-=A b_{k-1}^+\)，后验偏移为\(b_k^+=J_i b_k^-+G_i\eta_k\)。故后验传播矩阵为\(J_iA\)，预测传播矩阵为\(AJ_i\)。两者不可在范数与危险时标上混用。首个受攻包是k=7，最后一个是k=16，k≥17没有新注入；代码的停止尾部以k=16后验偏移为锚点，使用\(F_i^{k-16}\)，下标正确。

## 2. 水印与配对轨迹

代码发送\(q_{j,k}=M_{j,k}^{-1}y_{j,k}\)，只在目标编码域报文上加预定\(a_k\)，接收端乘同时间戳的M。结果为\(y_{j,k}+M_{j,k}a_k\)，本地量测不走不可信邻居接口。健康和受攻路径共享同一物理状态、过程噪声、测量噪声和水印，不同节点没有各自独立生成物理真值。

攻击支持为[7,17)，且仍是\(H_jA^t\xi\)。能量按编码域实际\(\sum\|a_k\|^2\)计算；没有以解码后能量偷换预算。由于共享的是原始量测而非估计，其他节点的内部估计不会因目标节点估计偏移发生多跳反馈；此处代码和原模型一致。

理想同步是在同一输入M数组下验证的数学接口，不是密钥分发、参数泄露、丢包错序或真实收发设备的工程验证。

## 3. 用不同残差基独立核算名义协方差

主实现用SVD左核基Z与过程噪声卷积矩阵W构造Θ。审查另利用本模型发送节点\(H_0=I\)，定义一阶差分

\[
e_r=y_{r+1}-Ay_r=w_r+v_{r+1}-Av_r.
\]

对r=0,…,s−1堆叠，其残差矩阵\(Z_\Delta\)为块双对角：每行块含−A、I。以精确有理A/Q/R核算

\[
\operatorname{Cov}(e_r)=Q+R+ARA^T,\quad
\operatorname{Cov}(e_r,e_{r+1})=-RA^T,
\]

非相邻块为0。\(Z_\Delta\mathcal O_s=0\)及满行秩均精确验证。令
\(T=Z Z_\Delta^T(Z_\Delta Z_\Delta^T)^{-1}\)，则主基应有
\(Z=T Z_\Delta\)、\(\Theta=T\Theta_\Delta T^T\)。两模型误差分别约`2.66e-15`、`1.11e-15`，不存在遗漏一个过程噪声或错用s+1个过程噪声的迹象。

主实现的完整重叠窗口联合协方差可以奇异；它没有直接对该大矩阵求逆，也没有假设相邻窗口独立。有限单目标链、28个评分的Bonferroni阈值只需单窗Gaussian与正确Θ，不依赖重叠独立性。它不是未知链路、无限监测或数据依赖择时的总体5%校准。

## 4. 与旧堆叠KF的差异不是只由初始化造成

审查独立以Bayesian精度形式

\[
P_{raw}^+=(P^{-1}+\sum_jH_j^TR_j^{-1}H_j)^{-1}
\]

计算一包自由堆叠更新，与`legacy_stacked_step`的增益形式结果在`1e-12`内一致。其邻居+self顺序、pinv和协方差jitter对应候选源码机制，但本轮不认证该源码整个历史运行的初始化/时段/数据版本。

目标节点原始逐邻居信息与先求和信息的差，精确有理计算为

\[
\sum_j H_j^TR_j^{-1}H_j-H_\Sigma^TR_\Sigma^{-1}H_\Sigma
=\operatorname{diag}(1/25,4/25)\succ0.
\]

因此即使匹配同一预测协方差，自由堆叠一般仍不等于共G。主测试进一步用邻居包相反扰动保持量测和不变：共G输出不变，自由块增益输出变化。此项是结构辨别用例，不是扩展主攻击或提出新攻击算法。
