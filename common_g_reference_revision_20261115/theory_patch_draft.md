## 4. 最小严格反例与不能混用的结论

1. **c1反例属于原模型类：** n=m=1，A=0、H=1、Q/R>0、s=1，局部可观；O=(1,0)ᵀ，Z=(0,1)，Δ=(ξ,0)ᵀ，非零D却ZDZᵀ=0。这里Z的第一时间块为0；不声称此前三个特定非退化模型有盲区。
2. **边界窗反例：** A=H=1，s=1，L=2，ξ=1，Z=(-1,1)，起点/内部/停止窗shift分别1/0/-1。内部奇偶隐蔽不等于全事件隐蔽。
3. **单位圆反例：** A为二阶单位Jordan、K=0、G=H=I，ξ=(0,1)给线性增长，ξ=(1,0)却有界；停止后F=0使下一后验偏移归零。持续与有限支持不能混说。
4. **编解码后效果：** m维Gaussian水印的E||Ma||²系数为λ²+2λq+(m+2)q²；a=b/q的encoded能量消失并不强制decoded能量消失，亦不直接证明任意KL预算可行。

这些属于正确性修复与标准数学结果，不作新水印贡献。首包oracle、GLRT、公开符号、已停止候选及第二篇冻结成果不移入贡献段。
