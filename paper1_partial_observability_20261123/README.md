# 第一篇论文：局部不可观测的50节点补充验证

研究日期：2026-11-23。**本轮已实际运行新的 n=4、m=2、50节点物理 Monte Carlo。** 这套配置专门回应“原二维满秩量测没有体现网络互补观测”的问题；它是显式登记的新补充模型，不能追溯替换历史二维结果。

## 结论与范围

原50节点拓扑、298条无向边、六条有向攻击支持及二维攻击通道波形均保留。状态由两个独立、动力学相同的二维子系统组成；偶数节点只观察第一个，奇数节点只观察第二个。每个节点的**时域可观测矩阵秩为2，全网为4**。量测和 Watson 水印仍为二维，故本轮不是 m>2 的高维水印实验。

本轮每个节点的一跳邻居就能补足缺失模态，尚未覆盖只能依靠多跳联合观测的更一般网络。新增维度使用两个相同动力学块，也不代表任意四维耦合对象已经验证。

固定负耦合相对 iid 的全网 MSE 配对差，在两个动力学上均为负，且名义95%配对区间不跨零。约98.6%的改善出现在接收节点本地未直接观察的二维状态块上。这是坐标损失的精确分解，不是新的因果门控归因实验。

不稳定模型的全时域评价中，负耦合也低于永久删除已知六边；稳定模型仍由永久删边占优。攻击期间两个模型均是永久删边更好，知道攻击支持和准确时段的更强 oracle 也在两个模型中占优。因此可支持的主张是**在某些局部不可观测配置中，保留正常时段的互补通信具有可量化价值**，不能称为对静态方法或 oracle 的普遍优越性。

## 已执行的物理实验

每个动力学独立使用512条健康校准路径、512条健康留出路径和512条受攻测试路径。三种固定 θ 在同一物理路径及共同随机数下比较；本轮没有新选参。阈值重新由新模型的健康整路径最大分数校准。MSE 是**每节点四个状态坐标的平方欧氏误差之和**，再对节点和时刻平均，不是每坐标误差，不能与历史 n=2 的 MSE 绝对值直接比较。

物理仿真采用理想精确解码后的报文模型 y+Ma，没有重新认证4维状态数值范围下真实编解码的有限精度误差或物理通信设备。

| 指标 | 不稳定 | 稳定 |
|---|---:|---:|
| iid，全网 post20 MSE | 1.40714197 | 1.36042019 |
| 固定负耦合 | 1.40544514 | 1.35464009 |
| 负−iid 配对差 | −0.00169683 | −0.00578010 |
| 配对差未调整95%区间 | [−0.00238857,−0.00100510] | [−0.00659698,−0.00496322] |
| 负相对 iid 的降幅 | 0.1206% | 0.4249% |
| 永久删除已知六边 | 1.40953164 | 1.34089766 |
| 已知六边及准确攻击时段 oracle | 1.38701419 | 1.32134788 |
| 独立健康路径报警 | 22/512=4.30% | 14/512=2.73% |

这些区间条件于本次实现的校准阈值，为近似配对 t 区间；不包含重新校准阈值的变异，也不是跨全部指标的有限样本安全认证。本次新配置只有固定原方向、原起点50、60拍攻击，没有开展12场景全网格或未知位置验证。三个固定水印的原始结果全部保留，包括表现较差的正耦合。

## 为什么永久删除与选择性接收产生不同结论

在健康路径上，永久删除这六边相对全部保留的全网 MSE 代价，不稳定模型为 **+3.0839%**，稳定模型为 **+2.7912%**。本轮每个节点确实缺少一个状态块，邻居提供互补信息，删边损失不再只是满秩本地传感器的少量冗余损失。

但必须分清评价窗口：post20 是 [20,150)，而攻击只有 [50,110)。不稳定模型中负耦合−永久删除的 post20 配对差为 `−0.00408650`，未调整95%区间为 `[−0.00501762,−0.00315538]`；六项网络主比较的描述性 Bonferroni 区间仍为负。**攻击期间**的同一差值却为 `+0.03470966`，说明主动门控仍承受漏接纳/检测时延的代价。

为避免把正常时段的信息保留收益解释为更强的攻击期抑制，本轮另补一个明确标注为**事后扩展**的强 oracle：只在已知的 [50,110) 删除已知六边，其余时刻全部保留。它在两个模型中都优于负耦合。该基线利用额外的精确攻击时段信息，不用于 θ 选择。

`eligible_link_time_alarm_fraction` 在真实检测候选中是报警/门控比例；在强制门控基线记录中只是指定的拒绝比例，**不能解释为该 oracle 的检测率**。

## 理论与实现验收

- [理论与证明](THEORY.md)：必要模态不可见时任意 K/G 都无法将该模态稳定；数据相关门控的窗口收缩界；相同平均丢包率、不同连续丢包结构导致不同模态风险的精确说明模型。
- 每个动力学57个局部模式重新求4维 nominal DARE。所有实际聚合观测秩均为4；保留的异类邻居最少1个。最大的数值二范数分别为0.642835和0.633140。该范围仅覆盖六条登记边，不覆盖任意邻居删除。
- 独立后验 Riccati 迭代重算所有114组增益，与 DARE 增益最大差约 `3.34e-13`。
- 两条物理路径、逐拍轮换全部64联合掩码，literal逐邻居更新与aggregate更新最大差约 `5.97e-10`；不稳定物理状态幅值放大了绝对舍入差。
- 内生门控配对递推在 n=4 下重新核验，最大残差约 `1.83e-10`；没有复用旧 n=2 的精确有理数收缩证书。
- 缺失模态的外生 Markov 说明模型经独立高斯卷积方差核验。相同5%丢失率、a=1.2 时，p11=0.05/0.6 分别给稳态风险0.15625/0.48382，p11=0.8 则均方发散。该公式不直接套用于实际数据相关门控。

## 文件与复现

`registration.json` 是运行前写定的本地探索配置，不是外部时间戳预注册。`derived_configuration.json` 保存完整4维 H/A/Q、原图和攻击边；`unstable_gain_design.json` 与 `stable_gain_design.json` 保存新模式增益及映射。`partial50_paths.npz` 保存102组路径数组，`partial50_results.json` 保存原始摘要、种子和来源哈希。`partial50_analysis.json` 与 `timing_oracle_*` 保存读回及额外强基线。

需要完整 `paperlast` 中的原源目录和同级 SSCD v3 包；Python 依赖 NumPy、SciPy，原工程辅助配置还需 mpmath。

```bash
python paper1_partial_observability_20261123/run_partial50.py --execute
```
