## **第一篇论文：四维局部不可观测实验的审阅结论**

我已核对 GitHub 提交 [`ae885b6`](https://github.com/center-666/paperlast/commit/ae885b6a9f9575bb0fbd7af89e489c07d251f198?utm_source=chatgpt.com) 中的模型定义、共 \\(G\\) 增益代码、理论证明、实验注册、512路径结果及独立审计记录。



**这轮比此前单纯扩展状态维数更有意义：它首次在当前研究中验证了水印收益能够传递到节点必须依靠邻居信息才能估计的状态分量。**



我确认以下三项结果有充分的现有证据支持：

1. **局部不可观测是严格成立的。** 每个节点的时域可观测秩为2，而四维状态在登记的保留邻居模式下具有可观测秩4；这不是简单地用一个秩亏的瞬时 \\(H_i\\) 冒充时域不可观测。
2. **负耦合的改善确实集中于本地未观测状态块。** 不稳定模型中，缺失块改善占全网总改善的约98.63%；稳定模型约98.61%。这与邻居互补信息机制相吻合。
3. **负耦合没有全面击败删边策略。** 不稳定模型在包含健康时段的整体 MSE 上优于永久删边，但攻击期间反而更差；知道攻击准确起止时刻的强 oracle 在两种模型中都更好。

有一点值得特别强调：新的系统仍为 \\(n=4,m=2\\)，使用两个相互独立、动力学相同的二维状态块。因此，它证明的是**局部不可观测和一跳互补观测下的适用性**，还不是一般高维耦合动力学或 \\(m>2\\) 水印的验证。

删除通信链路 **35 → 26** 后，节点26剩余的本地和邻居量测都无法观测第二个二维子系统。

对于不稳定模型，缺失子系统的开环最大特征值模为：

\\[ \rho(A\_{\mathrm{missing}})=1.0919258>1. \\]

因此，**永久删除这条关键互补链路会造成节点26的局部不可检测性**。在保持节点26只能使用自身和一跳邻居量测的条件下，不存在能够稳定该不可见不稳定模态的固定 \\(K/G\\)。



这不是说水印能够弥补已经丢失的观测信息，而是指出了一个更有价值的防御问题：

> 当一条通信链路既可能被攻击、又是某个节点估计不稳定模态所必需的信息来源时，防御者如何在拒绝污染和保留可观测性之间做出安全选择？

**我认为这比继续在原六条仍有冗余的攻击链路上扩大 Monte Carlo 更值得研究。** 原六边实验应继续作为主要基准，35 → 26 则作为明确新增、单独注册的关键互补链路压力实验，不能冒充原始历史攻击配置。

## **新增理论：关键互补链路上的安全估计边界**

在冻结的四维模型下，节点26缺失的二维状态满足：

\\[ x\_{k+1}^{u}=A_2x_k^{u}+w_k^{u}. \\]

如果35→26连续 \\(D\\) 拍被拒绝，且节点26无法从其他可信渠道获得该状态块，那么无论使用什么本地估计策略，都有：

\\[ \boxed{ \mathbb E\\|x\_{k+D}^{u}-\hat x\_{26,k+D}^{u}\\|^2 \ge \operatorname{tr} \left( \sum\_{h=0}^{D-1}A_2^hQ_2(A_2^h)^\top \right) } \\]

这是由不可观测过程噪声产生的误差下界。

这揭示了论文必须面对的一个基本限制：



**如果攻击者持续控制唯一互补信息通道，水印可以帮助识别污染，却不能凭空恢复被彻底拒绝的真实观测。**



反过来，如果拒绝只是短暂发生，现有共 \\(G\\) 结构仍可能保持稳定。



我进一步构造了节点26的合法回退增益：当35→26被拒绝时，只利用本地及同类邻居估计可观测状态块，缺失块采用开环预测。对应的全网齐次矩阵满足：

\\[ \\|F\_{\mathrm{keep}}\\|\_2\le0.642836,\qquad \\|F\_{\mathrm{drop}}\\|\_2\le1.098729. \\]

因此，如果任意连续5拍中至少1拍保留关键互补观测，就有保守的乘积界：

\\[ \boxed{ \\|F\_{k+4}\cdots F_k\\|\_2 \le(1.098729)^4(0.642836) <0.937<1. } \\]

这是一项**允许有限连续拒绝的充分稳定性条件**。它还没有证明实际检测器会满足该条件；这一点必须通过真实门控序列验证。

## **对第一篇论文创新性的进一步判断**

这次查新还发现一篇非常近的2026年工作，Watermarking-Based Attack Detection for Sensor Networks with Intermittent Observation Under Stealthy Attacks，已经研究了间歇观测下的分布式水印检测及 Kalman 共识缓解。另有部分通道编码和双层水印检测研究。

sysmath.cjoe.ac.cn+2



因此，我们不能把“水印检测后选择性隔离”或“间歇观测下的稳定性”本身包装成首创。



我建议第一篇论文把潜在的独特贡献收束为：



**在保持单拍 Gaussian 水印分布不变的前提下，根据系统的互补观测结构和状态损伤风险，设计有符号的跨拍水印相关性，使检测门控尽可能保留有价值的邻居信息，同时限制攻击污染。**



当前四维512路径实验支持这一方向，但还缺关键互补链路下的实测结果，以及真正优于固定负耦合的系统感知选参证据。



下一关很明确：**检验负耦合能否在真正不可随意删边的系统中改善最终估计风险，并如实识别它无法解决的观测信息缺失边界。** 这比继续增加一般性的二维随机算例更有可能形成第一篇论文有说服力的核心贡献。
