# 报警后按类别选权重的开发比较

日期为 2026-11-27。我们比较了一个统一权重、U/R两类权重、U不稳定/U稳定/R三类权重、已发布冻结表 \(T\)，以及单参数归一化创新饱和策略。七档权重均经过相同的 M7 当前历史合法集向上投影。固定阈值、禁重复四态水印、common-G估计器及目标边35→26不变。

## 路径分工与边界

权重拟合只使用任务3 purpose 4 的训练路径，每配置、每输入各256条。各权重锁定后，在 purpose 5 的连续和六开四关路径评价，每配置、每输入各256条。健康性能使用独立 purpose 6 路径，每配置256条。连续/突发及配置按注册方案等权，完整路径是重采样单位，20,000次 paired bootstrap 给出逐项95%区间。

这份比较是开发结果。purpose 5/6 先前用于其它冻结策略的开发筛查，故本次结果不能称为全新独立确认。全新确认路径仍待生成。本轮 purpose 4/5/6 实际输入全部按种子树重建，并与归档数组逐元素一致。[输入回生核验](INPUT_REGENERATION.json)

## 训练路径选出的规则

| 规则 | 报警时原始请求权重 |
|---|---|
| 统一 | 所有工况 \(q=0.6\) |
| 两类 | U \(q=0.6\)，R \(q=0\) |
| 三类 | 不稳定U \(q=0.8\)，稳定U \(q=0.6\)，R \(q=0\) |
| 冻结表 \(T\) | 不稳定U 0.8，稳定U 0.6，R 0 |
| 创新饱和 | \(c=2.0\)，\(w_k=\min(1,c/d_k)\)，量化至七档 |

创新距离 \(d_k\) 使用当前未加权原始报文与本地预测残差，并以接收端按本策略动作递推的名义预测协方差白化。阈值在训练路径上对所有12配置及两类输入等权选择。表中请求与 M7 投影后的实际权重分别归档。五种方案在本次评价路径上均为零 M7 违规和零投影。[训练参数与网格损失](FIT_PARAMETERS.json) · [逐路径动作档](pathwise_actions.npz) · [动作复核](ACTION_VERIFY.json)

## 统一表与分类表的差异

全12配置的节点26后两维攻击窗MSE如下。每格是两个输入及12配置的等权均值。

| 策略 | 训练选出的表 | 评价 MSE |
|---|---|---:|
| 统一权重 | \(q=0.6\) | 4.27482 |
| U/R两类 | U 0.6，R 0 | 3.79850 |
| U不稳定/U稳定/R三类 | 0.8，0.6，0 | 3.76596 |
| 冻结表 \(T\) | 0.8，0.6，0 | 3.76596 |
| 创新饱和 | \(c=2.0\) | 4.67501 |

两类表减统一权重的主要配对差为 **−0.47632 [−0.47947, −0.47316]**。这项总体收益完全来自R：R组差为 **−0.95264 [−0.95892, −0.94641]**。U组两类表和统一权重都取0.6，动作及损失相同。因此，报警后分清“有替代来源的R”与“唯一互补来源的U”在本模型中带来明确收益。

R组的平均闭环MSE由1.96264降至1.00999，约降低48.5%。不稳定U组由统一/两类表的7.26557降至三类表的7.13542，约降低1.8%。全局三类表相对两类表只降低约0.033，即全局平均MSE的约0.8%。这分开量化了替代来源分类的主体收益与动力学子类带来的较小增量。

三类表相对两类表的全配置差为 **−0.03254 [−0.03713, −0.02804]**。这部分来自不稳定U额外使用0.8。不稳定U组差为 **−0.13015 [−0.14840, −0.11193]**。稳定U组未出现额外差异。三类表与原冻结表 \(T\) 在全部开发评价动作上完全相同。[全部分组与配对结果](paired.csv) · [配置和动作摘要](evaluation.csv)

跨场景等权汇总中，冻结T相对统一0.6的攻击窗差为−0.50886 [−0.51445, −0.50323]。T并不在所有类别优于调优后的统一值。三类分类收益在R中有来源识别贡献，在不稳定U中另有动力学子类贡献。逐配置结果显示每组的具体收益迁移，不应将全局平均当成所有配置均改善。

主格不稳定U、R35×2中，统一和U/R两类都取0.6，攻击窗MSE为7.34875。三类表和冻结表取0.8，MSE为7.11820，配对差 **−0.23055 [−0.26259, −0.19966]**。差异在六开四关关闭拍为 **−0.55955 [−0.58498, −0.53458]**，活动拍为 **+0.00176 [−0.03213, +0.03549]**。用此前未公开的任务4 namespace85路径作交叉检查，T相对报警后固定0.6的MSE配对差为 **−0.23600 [−0.25774, −0.21450]**，方向一致。[namespace85同路径消融](../fusion_attribution/paired.csv)

## 创新饱和策略

饱和策略在全配置的受扰MSE比T高 **+0.90905 [+0.89474, +0.92334]**。在突发活动拍高 **+1.20705 [+1.19115, +1.22274]**，在关闭拍低 **−0.23255 [−0.23908, −0.22598]**，恢复窗低 **−0.05410 [−0.05608, −0.05210]**。健康MSE差为 **−0.000022 [−0.000117, +0.000108]**，区间跨零。

在主格中，T的31,911次目标报警全部执行0.8。饱和策略的原始权重均值为0.736，量化后0.2、0.4、0.6、0.8、0.9、1.0分别执行93、6,501、8,562、4,061、1,880、10,814次。其受扰MSE比T高 **+1.05613 [+0.98658, +1.12813]**。关闭拍略有改善 **−0.03215 [−0.05984, −0.00384]**，活动拍则高 **+1.25432 [+1.17902, +1.33244]**。它在关闭和恢复窗口提供了有意义的权重适应，但没有改善主要攻击窗端点，也没有改变本轮分类表的结论。

## 结论

调好的统一权重 \(q=0.6\) 是有力基线。按 U/R 分类带来约0.48的全局MSE增量收益，且差异集中在可用替代信息的R链路。三类表相对两类表另有约0.033的全局收益，主要体现在不稳定U的间歇关闭拍。现有证据支持把“是否存在替代来源”作为第一选权信息，并把不稳定U加权作为次级改进。创新饱和不是全窗MSE上的胜者，但其关闭拍与恢复收益指出了后续可以研究的报警后恢复问题。以上仍是已暴露开发归档上的比较，下一关应使用新随机流独立确认。
