# 早期预测表的作废说明

本目录中的 `KEY_PREDICTABILITY.csv`、`KEY_VARIATION_SUMMARY.csv` 和对应旧分析脚本保留作审计记录，不应作为结果引用。重审发现旧变体摘要把两折交叉拟合输出按512个物理路径各重复了一次，另一折占位为零，导致同一物理路径双计。旧预测器还使用真实攻击起点加八拍作为纳入条件，泄漏了在线不可读的起点信息。

`PREDICTION_*` 文件以旧 Task4 物理路径重新计算修正版。它在全时间索引生成特征，只使用预测时刻之前的报文和合法密钥。每个物理路径每个变体只输出一行，交叉拟合折由 path ID 唯一决定。该修正仍是已解封路径上的事后开发，不构成独立确认，也没有计算补偿闭环收益。

旧文件没有删除，便于核对这次口径更正。以 `PREDICTION_RECEIPT.json` 记录的代码、输入和输出哈希为准。
