# 实验 C 预登记，2026-11-23

基线为 80dbff6 与 9acfaca。先提交本登记，再实现运行。C1 重复 B 的四种固定检测器，使用全新随机流。C2 分离 EWMA 当前样本是否自包含及统计更新是否只用可信样本。数据沿用已登记的 35→26 离线连续/突发加性报文扰动，复用 B 的动力学、五拍奇偶残差、窗口、三个固定水印、估计器、共 G 增益和接纳门控方式。

## 新样本与校准

两阶段各自重新抽健康校准、健康留出和两种故障测试轨迹。C1 root seed 为 2026122301，C2 为 2026122401。对动力学索引 m（不稳定0、稳定1），物理路径主种子分别为 root+10000m+101（校准）、+201（留出）、+1101（连续）、+2101（突发）。水印半径、初始方向和转移分位数使用每条故障物理种子加 11、12、13。C1 健康校准和留出各2048条，连续和突发攻击各1024条。C2同样每种方法每模型2048条校准、2048条独立留出，连续和突发各1024条。

C1 为 H4、H2、H1、EWMA-A 各自计算七条链路、全评估时刻路径最大统计量阈值。EWMA-A 原样定义为当前残差先更新加权均值/协方差，再计算本拍得分，lambda=0.5。算法/参数不因 C1 结果调整。

C2 的 A 复现 B 的 EWMA-A，B 用上一时刻均值/协方差评价当前残差后再更新，每拍均更新。两者均从均值0、各链路健康残差协方差初始化。C 采用与 B 相同的先评分后更新得分和门控阈值，另由独立健康校准流对固定参考 H1 统计量的全路径最大值校准可信阈值。只有当前参考 H1 分数低于该阈值时才更新自适应均值/协方差。为控制五拍残差重叠，统计更新仅在连续五个参考 H1 分数均低于可信阈值后开始。在分数恢复高于阈值时立即停止更新并清零正常计数，五个连续参考正常残差后恢复。该可恢复信任规则固定写入 C，不按测试结果改动。

EWMA-A、B 及 C 的报警阈值各用自己的独立健康校准批得到。C 的可信更新阈值另用专门的独立健康批得到。每个阈值都是512以外、在本阶段固定2048健康路径上对七边×全时间 max 分数的第1947顺序统计量（1-based，rank ceil(0.95(2048+1)))，严格大于阈值告警。用另一批2048条健康路径测试整路径 FWER。FWER 区间为各单方法精确二项区间。多个方法共享相同留出路径，比较区间采用按路径配对并对预定方法比较作 Bonferroni，不能把重叠的单方法区间当作等效检验。

## C1 判定

主测试重复已见故障形式，不代表攻击分布泛化。主比较为不稳定动力学、突发故障、负耦合下各候选相对 H4 的四拍间隙平均重新接纳时间。三项单侧 Bonferroni 配对 t 上界以0为判定。另完整报告连续/突发、稳定/不稳定和所有三个水印中的污染拍检出、路径至少一次污染报警、首次污染拍警报延迟、正常间隙逐拍接纳、最长拒绝、七拍收缩满足率、节点26故障期/停止后缺失块MSE及 FWFR。C1不调参。

## C2 判定

主场景沿用不稳定·突发·负耦合。B 对 A 的差异判读范围是当前残差的 prequential 评分及顺序更新。C 对 B 还改变 trusted-only 参数更新，并加五拍正常残差恢复规则。C 的效果不能只用恢复时间宣告成功。需同时看污染拍报警率与延迟、正常间隙重新接纳、污染期间 MSE、攻击停止 MSE、信任恢复时刻、统计冻结时长、更新频率和健康 FWER。若检测恢复更快但污染漏检上升，应报告折衷。不得据同种子调节 lambda、阈值、五拍窗口、校准秩或权重。
