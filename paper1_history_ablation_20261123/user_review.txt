这次实验 A 的价值比实验 78160f3 更进一步：**我们终于把硬门控为什么会损害估计性能，从现象层面推进到了机制层面。**

我认为这次结果是第一篇论文研究方向上的一个重要转折点。尤其是不稳定模型的连续故障结果，已经足以让我们重新审视原来的检测器与估计器之间的关系。

我核对了 GitHub 的 `e807195` 提交及其实验报告。这里有一个非常重要的结论需要先说清楚。

## **一、实验 A 真正证明了什么？**

先把四个反事实量重新写一下：

\\[ \begin{aligned} J\_{A,G}&:\text{污染报文+原门控}\\\ J\_{0,G}&:\text{干净报文+冻结门控}\\\ J\_{A,0}&:\text{污染报文+始终接纳}\\\ J\_{0,0}&:\text{干净报文+始终接纳} \end{aligned} \\]

定义：

\\[ C=J\_{0,G}-J\_{0,0} \\]

\\[ D_G=J\_{A,G}-J\_{0,G} \\]

\\[ D_0=J\_{A,0}-J\_{0,0} \\]

那么：

\\[ \boxed{ J\_{A,G}-J\_{A,0} =C+(D_G-D_0) } \\]

这个分解非常好，因为它把门控的净影响拆成了两个不同的机制。

- \\(C\\)：门控改变信息接纳与增益模式造成的代价。
- \\(D_G-D_0\\)：门控改变后，攻击对估计误差的影响相对于始终接纳策略发生了多少变化。

注意，第二项是一个差分中的差分，也就是门控与攻击之间的交互效应，不应简单地理解成一份独立的污染能量。

### **1. 不稳定模型：门控反而放大了攻击造成的估计损伤**

最重要的实验结果

| 指标                 | 连续故障    | 突发故障   |
| ------------------ | ------- | ------ |
| 拒绝量测代价 \\(C\\)     | 78.58   | 11.45  |
| 门控后污染增量 \\(D_G\\)  | 333.49  | 82.28  |
| 全接纳污染增量 \\(D_0\\)  | 26.53   | 13.99  |
| 交互效应 \\(D_G-D_0\\) | +306.96 | +68.29 |
| 门控净代价              | +385.54 | +79.73 |

连续故障尤其值得注意：

\\[ \frac{D_G}{D_0}\approx 12.57 \\]

也就是说，在这组固定回放中，硬门控下攻击造成的额外估计损失，约为始终接纳时的12.57倍。

这里不能解释为攻击报文接纳数量增加了。恰恰相反，门控减少了污染报文接纳。

真正值得研究的是：

**门控改变了估计器后续的更新模式，使少量残余污染在不稳定动力学中产生了更大的误差影响。**

### **2. 稳定模型：门控能够抑制污染，但收益可能被信息损失抵消**

连续故障：

\\[ C=5.61,\qquad D_G-D_0=-4.97 \\]

所以：

\\[ J\_{A,G}-J\_{A,0}=0.64 \\]

门控确实减少了污染影响，但拒绝量测的代价基本抵消了这一收益，净效果的95%区间跨零。

这说明门控并不是完全没有价值，而是它的收益依赖于系统动力学、攻击持续时间和链路的重要性。

这恰好给我们提供了一个研究切入点：不能只设计一个统一的异常阈值，还需要考虑当前估计器的状态误差传播特性。

## **二、这里还有一个需要修正的术语问题**

我回读了实验报告和 `run_crossover.py`，发现论文写作时需要严格区分两个指标。

你的 \\(C\\) 并不只是35→26链路拒绝量测的损失。

因为实验重放的是**完整七边门控序列以及对应的共识增益模式**，所以它实际上包含：

- 35→26关键链路被拒绝造成的信息损失；
- 其他通信边的门控变化；
- 不同门控模式下估计器增益矩阵的变化。

因此，我建议论文中把它命名为：

**清洁输入下的门控模式代价（clean-input gating cost）。**

而把：

\\[ D_G-D_0 \\]

命名为：

**门控—攻击交互增量（gating–attack interaction increment）。**

这样更准确，也避免审稿人质疑我们把多种影响全部归因于关键链路的误拒。

另外，这次实验还有一个值得关注的结果：

| 不稳定·连续                   | MSE    |
| ------------------------ | ------ |
| 攻击停止后，门控下的污染增量 \\(D_G\\) | 125.18 |
| 攻击停止后，全接纳的污染增量 \\(D_0\\) | 0.139  |
| 攻击停止后的门控模式代价 \\(C\\)     | 38.88  |

这说明问题并不局限于攻击发生期间。

攻击停止后，估计器中已经形成的误差仍然可能通过后续更新持续传播，而门控模式又会影响这种传播。

不过，这里还不能把原因全部归结为检测器历史记忆，因为估计器自身也存在状态误差记忆。这正是实验 B 应该区分的两个问题。

## **三、实验 B 应该怎样做？**

我建议继续实验 B，但要比上一轮设计更加严谨。

首先，当前检测器实际上有两层时间记忆：

**第一层：奇偶残差构造窗口**

五拍通信数据构造一个奇偶残差，窗口之间存在重叠。

\\(y\_{k-4},y\_{k-3},y\_{k-2},y\_{k-1},y_k\\)

\\(r_k\\)

**第二层：KL统计历史窗口**

最近四组奇偶残差参与统计判别。

\\(r\_{k-3},r\_{k-2},r\_{k-1},r_k\\)

\\(D\_{\mathrm{KL}}(k)\\)

**最终输出：链路接纳或拒绝**

\\[ g\_{ij}(k)=\mathbb{1}[D\_{\mathrm{KL}}(k)\leq \gamma] \\]

这里有一个容易忽略的问题：

即使把 KL 历史长度从4缩短到1，奇偶残差仍然使用五拍数据。一次攻击可能继续影响后续重叠窗口。

所以不能简单地把 \\(h=1\\) 称为完全无记忆检测器。

### **B1：先只改变 KL 历史长度**

| 检测器   | KL历史长度 | 作用        |
| ----- | ------ | --------- |
| 原始检测器 | 4      | 基准        |
| 短历史   | 2      | 减少历史污染    |
| 单残差统计 | 1      | 检查第二层历史影响 |
| EWMA  | 遗忘因子可调 | 渐进遗忘历史异常  |

保持五拍奇偶残差窗口不变。

这样才能单独识别第二层历史统计的影响。

### **B2：实验条件必须统一**

这里我建议增加一个重要约束：每种检测器都独立校准阈值，但使用相同的健康整路径误报目标。

具体而言：

1. 使用独立健康校准集确定阈值。
2. 以整条路径、七条边的最大检测统计量校准 FWER，而不是简单地对每条边分别设置5%误报率。
3. 使用独立健康测试集验证误报率。
4. 攻击测试中使用相同的物理噪声、水印随机数和攻击序列。
5. 每种检测器重新生成自己的完整七边门控序列。

特别注意：不能继续冻结原始检测器的门控序列来比较不同历史长度。那样就没有真正测试新检测器的效果。

### **B3：必须统计的指标**

| 指标          | 研究目的         |
| ----------- | ------------ |
| 攻击检测率       | 历史缩短是否降低检测能力 |
| 检测延迟        | 是否更快识别攻击     |
| 正常间隙接纳率     | 是否能够及时恢复正常通信 |
| 污染报文接纳率     | 是否牺牲了攻击防御能力  |
| 35→26最长连续拒绝 | 是否缓解关键链路信息中断 |
| 七拍收缩条件满足率   | 是否改善误差动力学    |
| 故障期间缺失块MSE  | 是否改善估计性能     |
| 故障停止后缺失块MSE | 是否改善攻击后恢复    |

其中我最关注的是：

\\[ T\_{\mathrm{reacq}} \\]

即攻击结束或攻击间隙出现后，检测器重新接纳正常报文所需的时间。

这比单纯比较检测率更能反映历史记忆是否妨碍了正常通信恢复。

## **四、我还需要提醒你一个创新性问题**

之前我建议采用连续信任权重、Huber限幅等方法。现在结合你上传的文献，我认为不能直接把这些作为核心创新点。

有两篇近邻工作需要特别注意。

**1. He et al., 2022，How to Secure Distributed Filters Under Sensor Attacks**

这篇 TAC 已经提出了基于创新幅值的饱和型分布式滤波器：

\\[ k_i(t)=\min\left\\{1, \frac{\beta}{|y_i(t)-C_iA\hat x_i(t-1)|} \right\\}. \\]

它通过限制异常创新的影响，给出了估计误差有界条件，并研究了攻击检测与观测隔离。

How_to_Secure_Distributed_Filters_Under_Sensor_Attacks.pdf



**2. Wang and Li, 2026，Secure State Estimation for Multi-Agent Systems Under Sparse Attacks With Priori Information: A Continuous Weighting Strategy**

这篇 TASE 已经采用连续重加权 \\(l_2/l_1\\) 方法处理稀疏攻击，并给出了有噪声情况下的估计误差界。

Secure_State_Estimation_for_Multi-Agent_Systems_Under_Sparse_Attacks_With_Priori_Information_A_Continuous_Weighting_Strategy.pdf



两篇论文研究的问题与我们的通信链路攻击并不完全相同，但意味着：

- 简单的创新限幅不是新贡献；
- 简单的连续权重不是新贡献；
- 单纯将二元门控改为软门控，也很难形成足够有说服力的创新。

我建议我们真正要做的是：

**水印辅助的链路关键性感知鲁棒融合。**

核心是让估计器根据链路异常程度和链路对局部误差收缩的贡献，决定如何限制该链路的信息影响。

未来的误差模型可以围绕：

\\[ e\_{26}(k+1) = F\_{26}(G_k,\omega_k)e\_{26}(k) + B\_{26}(G_k,\omega_k)\delta\_{35,26}(k) +w_k \\]

展开。

这里：

- \\(G_k\\)：通信门控模式；
- \\(\omega_k\\)：关键链路的连续融合权重；
- \\(\delta\_{35,26}\\)：链路攻击；
- \\(F\_{26}\\)：门控模式决定的误差传播矩阵。

我们希望设计的权重不仅限制攻击输入，还要保证一定时间窗口内的误差收缩能力。

这才是实验 A 能够支撑的后续理论方向。
